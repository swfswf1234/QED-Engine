## 1. 定位与目标

「探索」是管理中心的界面（替换已删除的原始文档对照菜单位），面向**单本已解析书目**：

- **文档切分**：把解析产物（blocks 结构化块）切成适合检索与学习的知识单元，检查切分
  边界是否截断完整句/公式（chunking-notes.md 的数学文档特殊性）；
- **文档召回**：通过**对话方式**对切分结果做检索验证——提问 → 召回相关块 → 展示命中
  与溯源（页/块级），人工判断召回是否准、是否全（rag-notes.md 关键点）；
- 目的：整理知识——切分与召回的产出（块级知识单元）是后续学习中心课程学习与知识问答
  的知识底座。

与[学习中心](learning-center.md)知识问答的关系：探索是**管理侧的技术校验与知识整理**
（对单书逐块核对、调参、人工确认）；学习中心问答是**用户侧的最终形态**（多 Agent 编排、
课程级知识链路）。探索先行，问答后置。

## 2. 界面形态（规划草案）

```
#/admin/explore（探索）
┌───────────────────────────────────────────────────────────────┐
│ 探索：{书目 Select}                     [切分参数] [新建对话]   │
├──────────────┬────────────────────────────────────────────────┤
│ 左：切分结果  │ 右：对话（召回验证）                            │
│ 块列表        │  Q: 什么是上确界？                             │
│  (段落/公式/  │  A: 来自 p0032 第 2 段：……（引用溯源可点击）    │
│   表格，按页  │     来自 p0033 公式 1.7：……                    │
│   折叠)       │  命中块高亮 + 相似度/来源标注                    │
│ 切分边界      │  追问/切换书目/调整切分参数再验证               │
│ 问题标记      │                                                │
└──────────────┴────────────────────────────────────────────────┘
```

- **切分**：以 blocks 为切分点（paragraph/formula/table 天然单元，Axiom-Flow 设计文档
  已明确「块级向量化，无需 LangChain 文本切分器」）；参数面板（chunk_size / overlap /
  分隔符策略）供实验，展示切分边界与截断警示（公式腰斩/跨块语义）。
- **召回**：对话方式——提问经检索链路（向量 + BM25 混合 → rerank）返回 top-k 块，
  展示命中块 + 引用溯源（书/页/块），人工判定召回质量；无向量库阶段可先用关键词/BM25
  简易检索做召回验证（chunking-notes 验证方法：抽样看切分边界 + 下游命中率）。
- **产出**：人工确认的知识单元（块 + 标签/备注）登记落库（af_* 扩展或学习表族，
  归属设计时裁决），供学习中心消费。

## 4. 前置依赖与实施顺序

| 前置 | 状态 | 说明 |
| --- | --- | --- |
| 文档解析管理闭环（af_books 同步 + 块级对照 + 判定） | 本轮实施 | 书目基座与块级渲染复用 |
| 解析产物质量达标（公式可渲染率 ≥90%，V2-008） | Axiom-Flow 验收 | 召回质量依赖产物质量 |
| 检索链路选型（向量库 Milvus 等，V2-009 方向） | 探索项 | 阶段一可用 BM25/关键词简易召回 |
| LLM 网关（对话模型接入） | 学习中心第二轮 | 对话问答依赖，可用本地 LM Studio 先行 |

实施顺序建议（各阶段独立立轮）：

1. **探索 v0（切分校验）**：块级切分预览 + 边界/公式完整性检查 + 人工标记问题
   （依赖解析管理轮组件，纯前端 + 8902 只读）；
2. **探索 v1（简易召回）**：BM25/关键词对话式召回验证 + 溯源展示（不依赖向量库）；
3. **探索 v2（向量召回）**：向量库接入（Milvus，Axiom-Flow V2-009）+ 混合检索 + rerank，
   与学习中心检索链路合并评估（99% 目标）。

## 5. 验证与成功标准（规划）

- 切分：抽样 20 页无公式腰斩、无跨块语义断裂（对照 chunking-notes 验证方法）；
- 召回：冻结问题集（每书 10~20 题）命中率与 top-k 精度可观测、可对比参数；
- 溯源：答案/命中块可点击跳回原页原块（解析管理对照视图复用）。
