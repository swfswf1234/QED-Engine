## 1. 定位与目标

本文档是「学习中心·课程学习」两屏（书架清单 `#/learn` ＋ 单课工作台 `#/learn/c/:learnCourseId?book=`）的
**UI 设计事实源**：页面信息面、阅读单位、三栏职责、正文排版规则、学习交流三段、推进动作位置、文案禁现口径，
以及空态与降级的用户可见表现。

它回答的是「学习者如何把一门课**按知识点一条条读完**，并在一屏内看到「学到哪」「这一条的知识」「学过与记下」」。
本面只**消费**后台管理·文档分析处理（REQ-116 职责①②③）产出的成品——已确认目录、已确认知识点、
已关联习题（与课后练习的联动**只发生在数据层**，界面无出口）。

- **服务对象**：学习者本人。上游入口唯一＝首页「课程学习」卡 → `#/learn`。
- **成功标准**：① 阅读单位＝「章 ＋ 知识点」两级，节层不显形；② 界面零过程性词汇（解析／链路／编译／单元／
  页窗等一律不出现），每条降级话术都给下一步；③ 目录栏只列名称与自己的「已学」标记，处理进度类说明不入学习面；
  ④ 正文按标题层级两档左对齐、跨页段落相连，界面无页码与「继续加载」；⑤ 推进动作只落在正文末尾三枚，
  同条再点「已掌握」＝撤销；⑥ 学习交流三段的读法与写面确定（章级成品写主表章行、条级详解写主表 `angles`、
  备注写学习记录 kp 行的 `learner_note`，零新表零新列）；
  ⑦ 8900／解析侧不可达时逐区降级不白屏；⑧ 面间零跳转（不去知识探索、不去课后练习）。

## 2. 范围与非目标

**范围内**：书架清单的同步展示口径与教材卡形态；工作台三栏信息面与断点版式；左栏目录两级形态与两档左缘；
中栏单条正文流的排版与续取规则；右栏「学习交流」三段的读、写与过滤口径；正文末尾推进三枚；
按需生成的前端消费语义；文案禁现与必含词守护矩阵；状态与降级矩阵。

**非目标（各给事实源指针）**：

- **知识点的生产与确认**（识别候选、人工确认入库、驳回）＝后台管理·文档分析处理面，见
  [REQ-116 设计稿](../../plans/2026-10-15-doc-analysis-processing.md)；学习面维持**零确认写面**。
- **目录的人工修正腿**（原「修改目录」弹窗与整树覆写入口）＝同上移交，学习面不再提供。
- **块切分质量**（解析产物粒度）＝[REQ-099 请求稿](../../plans/2026-09-26-req098-parsing-region-edit-typography-axiom-flow-request.md)
  R2／R5 口径，本轮只在排版层止血。
- **端点表与 DDL**＝[api-contracts.md](../../architecture/api-contracts.md) §⑥ 与
  [database-design.md](../../architecture/database-design.md)；本档不复述字段级契约。
- **习题作答与判分**＝[learning-practice-ui.md](learning-practice-ui.md)。
- **LLM 提问的后端功能腿**＝本面只放**入口**（输入框＋置灰发送＋「暂未开放」），零请求，功能归后续批。

## 3. 书架清单（`#/learn`）

清单是**服务端同步结果的展示**，不是管理面：教材在解析侧就绪即出现在书架上，界面不新建、不删除学习课程。

- **页头**：标题行右侧＝领域下拉（进场默认落在**第一个领域**，非「全部」哨兵）；导航右上角三枚＝
  使用手册／刷新／返回（「刷新」＝重新同步，不触发任何生产动作）。
- **课程行**：标题＝**共享表正式名称**（`qed_course.name`，R5 引用不复制、无名称快照列可回落）；
  状态徽章词本身承载口径＝`已结课`／`学习进度 N%`／`知识点未就绪`／`未开始`（`statusBadge` 纯函数单一来源）。
- **教材卡**：课程下**横排小卡片**＝书名＋面向对象档位徽章＋该教材进度（`N/M 条`，取 `derived.books`）＋教材套简介；
  卡上动作两枚＝「进入学习」（深链到该教材的工作台）与「忽略」。忽略＝教材级 `dismissed`
  （写在课程 `resources` JSON 键内，零 DDL），收起后进「已忽略」区可**按回来**。
- **教材出现条件**：解析侧就绪（激活版本存在）的教材才同步展示，未就绪者服务端 PASS、界面不列占位行。
- **降级**：8900 不可达＝空态＋离线提示，不白屏；解析侧不可达＝只列既有课程、刷新可重试。

## 5. 阅读单位与正文规格

### 5.1 阅读单位＝知识点（数据口径）

- 推进单位＝**知识点**：序列由 `GET …/knowledge-points` 的 `sequence` 给出（＝主表 point 行 × 章 outline ×
  kp 行三源在 8900 侧汇成），按章序 → 知识点 `order_hint`（全空时按创建序）投影；行标识用稳定派生键
  （`kp:{kp_id}`），**读时投影、零物化**——`qe_unit` 整表已随 [ADR 0026](../../adr/0026-v1-root-table-family-freeze.md)
  D2 退出，本面不再有「节／块」行，也不在进场时写任何行。
- 进度、百分比、结课判定、「已学」位一律按 **kp 行**读时计数（`derived.mastered`／`percent`／`completed`
  不落列）；课程顺序还可在 course 行 `config.kp_path` 上人为编排（数组序即学习序，缺键即按投影走）。
  字段与端点形状的事实源＝[api-contracts.md](../../architecture/api-contracts.md) §⑥。
- 断点续学＝服务端回显的 `derived.current_unit_id`（同一派生键，取第一条未掌握也未跳过者）；
  界面不出现「单元」「链路」字样，措辞用「这一条」「下一条」。

### 5.2 中栏排版（层级左对齐、跨页合并、噪声剔除）

1. **层级左对齐**：正文块左偏移＝其所属标题层级——章题 `0`、节题 `16px`、子题 `32px`，
   正文／公式／图表块与最近上级标题同档，并显式 `textAlign:'left'`（映射源＝`components/parsing/typography.ts`
   的 `roleTypography` 与 `BlockList.tsx` 的块样式）。
2. **左栏目录两档左缘**：章行 `padding-left: 8px`、知识点行 `22px`（＝`8 + OUTLINE_INDENT_PX(14)`），
   同档内**逐行相等**。落点＝`outlineRowStyle(level)` 纯函数 ＋ 单一常量 `OUTLINE_INDENT_PX`，由
   `LearnWorkbench.test.tsx` 的「两档左缘相等」用例与源码扫描共同守护。
   **不变量**：antd `Button` 内容是 flex 居中，单写 `textAlign:'left'` **完全无效**（左缘会随名称长度漂移），
   行样式必须同时给 `justifyContent:'flex-start'` ＋ 左内边距。
3. **跨页段落合并**：相邻两块同为正文且前块不以句末标点或冒号收尾 → 合并为一段（消除「句子从中间断开」）。
4. **标题归位与去重**：同一标题在页眉或跨页重印时只保留首个，并按第 1 条落到其层级档位。
5. **噪声剔除**：页眉页脚与页码块默认不渲染；题注紧随其图块。
6. **无页措辞**：中栏标题＝知识点名本体，不带页码；取材范围降为「本条正文出处」悬浮提示。
7. **续取不显按钮**：滚到已取块末尾自动续取下一批；到本条取材尽头显「这一条读完了：点「下一条」接着学。」

## 6. 右栏「学习交流」三段

栏题＝**学习交流**（「注解」只允许作段内内容词，不得再作栏题）。

- **段 ① 本章总结与学习要点**（恒在其上）：选中任一知识点或整章区域时，顶部恒显**所属章**的章节总结与
  学习要点（3~6 条）。读法＝进场一次直读；缺失才给「生成本章总结与学习要点」入口，生成即持久、重进直读。
- **段 ② 详解**（跟着选中的那一条走）：直读该知识点主表行的 `angles` 数组，**数组序即权威展示序**——前端
  不再自行排序、不显点赞，也没有「保留／待整理」这类中间态（REQ-117 C19 点赞腿与 C27 块级分组随候选池
  退出，v1.0 无承载，功能消失）。一条也没有时给「生成本条注解」入口，产出＝向 `angles` 追加一个元素
  （`angle` 取六词闭集 `summary`/`explanation`/`definition`/`theorem`/`proof`/`example`，同一 `angle`
  重复生成＝覆写该元素，不并存多版本）。这一条另外登记过长文正文时（主表 `narrative_ref` 非空），段内给
  「读这一条的正文」一条**文件读腿**（`GET /learn/knowledge-points/{kp_id}/narrative`，8900 直读 `parsed/**`，
  8903 不读文件）；指针悬空＝该腿空态并给下一步，不静默改写指针。段末给 **LLM 提问**入口＝输入框＋置灰
  发送按钮＋「暂未开放」，**零请求**。
- **段 ③ 备注**：学习者自由书写并可跨会话回看。落点＝学习记录 kp 行的 `learner_note` 单列（写面＝
  `POST /learn/courses/{id}/progress` 带 `note`，`status='pending'` 只落备注不动终态位），零新表零新列，
  属**人工位**（R6：机器永不写此列）。**边界两条**：① 该条**尚无 kp 行时备注存不下**——前端禁用保存并给
  下一步（「先用正文末尾的『已掌握并下一条』记上，备注就存得下了」），这是「pending＝无行、读时派生非累加」
  口径的必然推论；替代方案（非空备注即自动起一条 pending 行）会把备注变成 kp 行的第二个产面，**本轮未采、
  待用户复核**。② 备注**不作知识点提升来源**——提升腿整体归后台管理·文档分析处理面（REQ-116），学习面维持
  **零确认写面**；候选池时代的「三层事实隔离」随该表退出而不再需要。

## 7. 推进动作＝正文末尾三枚

右栏不再有「推进」段；推进只发生在**章／知识点正文的末尾**，三枚＝**上一条／下一条／已掌握并下一条**。

- 「已掌握并下一条」＝把当前知识点置为已学后自动前进；**同一条上再点一次＝撤销回未学**。
- 「跳过本条」「回到断点」「撤销勾选」等旧控件下线（后端状态闭集不动，学习面不再产生 `skipped`）。
- 界面措辞不用「节」「单元」；进度只在左栏「已学」标记与书架教材卡出现，页头与右栏无计数徽章。

## 8. 按需生成的前端消费语义

生成类请求**一律经 8900 业务端点**，前端不拼 prompt、不直调 `/llm/*`（口径见
[llm-gateway.md](../llm-gateway.md)）。设计态口径三条：

- **取材三级回落**：知识点自带页范围 → 来源锚点 → 所属整章页窗；零可用页时给「正文还没准备好，暂时生成不了」。
- **持久位**：章级总结与要点写在章行成品位（`summary` 与 `meta.chapter_key_points`，覆写、成品位单一）；
  条级注解写在 point 行的 `angles` 数组里（同一 `angle` 覆写该元素，不并存多版本——候选池时代的
  「多版本并存」随该表退出取消）。两端点合一枚 `POST /learn/annotations/generate`，按 `target` 分流。
- **超时与兜底**：生成类请求前端显式长超时（默认 8s 必超时）；同一目标 60s 内重复的章级请求直接回上次成品。
  上游失败／端点缺失（旧进程 404／405）一律转成**带下一步的中文话术**（「稍后点右上『刷新』再试」），
  不透传裸状态码文案。请求与响应形状的事实源＝[api-contracts.md](../../architecture/api-contracts.md) §⑥。

## 9. 文案净化与守护

- **后台口径词禁现**（全学习面）＝`BANNED_BACKEND_TOKENS`：解析、链路、编译、单元、登记、注册、管理面、
  `source_ref`、未激活、页窗、投影、镜像、离线、服务、LLM、8900、8902。
- **工作台旧口径禁现**＝`BANNED_V1_WORKBENCH_TOKENS`：学习工作台、修改目录、推进与批注、学习进度、未就绪、
  本节、上一节、下一节、本条学完、跳过本条、撤销勾选、回到断点、保留为候选，以及 v1.0 三张化后追加的
  **退场 tripwire** 一组＝点赞、待整理、已保留、确认入库、驳回、本条通用、这一块、候选、生成本条总结
  （候选池与保留位随表退出，这些词回来即判红，功能不许悄悄复活）。
- **目录禁现四类当前情况说明**＝`BANNED_TOC_STATUS_TOKENS`（正在为您整理／暂时没整理好／还没有可读的教材／
  知识点还在整理）：整理中／失败／无可读教材／章内零知识点属**后台管理要看的事实**，学习者只需知道能读什么、
  点了会怎样。
- **右栏必含词**＝学习交流、本章总结、学习要点、详解、备注、生成本条注解、长文正文、上一条、下一条、
