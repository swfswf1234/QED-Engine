## 1. 定位与目标

本文档是「学习中心·知识探索」**单一页面**（路由 `#/knowledge`；领域星图视图与课程层级星图
视图在同页内替换，课程层深链形态 `#/knowledge?course={course_id}`）的 **UI 设计事实源**：
页面信息面、背景层、布局坐标系契约、森林版式规则、三类图元（轨迹列框／课程框／先修连线）与
课程层两级图元（大知识点虚框／框内条目）的视觉与交互口径、同页下钻与面包屑导航、空态与降级表现。
它回答的是「学习者如何在一屏星空里看清一个领域的学习轨迹、层级与先修关系，并就地下钻到某门课的
知识点层级结构」。

- **独立面声明**：本面只出知识点体系浏览与下钻；**不含任何通往学习／练习界面的出口**
  （无「进入学习工作台」、无「今日复习」按钮或提示段）。进入学习＝首页「课程学习」卡→书架；
  进入练习＝首页「课后练习」卡→练习独立面（见 [learning-practice-ui.md](learning-practice-ui.md)）。
- **服务对象**：学习者本人；首页「知识探索」卡是唯一上游入口（href `#/knowledge` 不变）。
- **成功标准**：① 同一份数据每次画出同一张图（布局确定性）；② 同层级课程跨轨迹对齐成排，
  连线自上而下表达「先修→后修」；③ 连线落点在课程框边，不穿框不悬空；④ 界面本体零解释
  文字，读图口径全在使用手册；⑤ 数据未接入走空态不白屏；⑥ 全面无跨界跳转（独立性）；
  ⑦ 大标题「学习中心·知识探索」在两视图一致，课程层级视图＝层级星图（§9）且零写面；
  ⑧ 首页 Hero 不出现「仍在建设中」行；⑨ 两级视图在同一页面内替换（面包屑承担层级导航，
  不做整页跳转），星图课程卡悬停可读**课程名称与课程叙述**；⑩ 课程层与领域层用**同一套星图
  语汇**（暗色星空延续、虚框容器＋发光圆点＋名称标签），课程层左上角**不挂领域下拉、只显示
  课程名**；⑪ 课程层与领域层画在同一星空层上，版式＝**大知识点虚框自上而下按学习顺序堆叠、
  框内排小知识点条目**（圆点＋常驻名称标签），图区**宽度跟随容器**且缩放平移后整框可达；
  悬停只给学习者**名称＋摘要**（来源锚／四分类／下辖计数不进学习面）。

## 3. 页面信息面与导航（单页两视图）

**一个页面、两级视图**：领域星图视图与课程层级星图视图（§9）在 `#/knowledge` 同页内替换，
层级路径由面包屑承载；不设第二个页面、不做整页跳转。

| 位置 | 内容 | 口径 |
| --- | --- | --- |
| 页头左 | 大标题「学习中心·知识探索」 | 两视图一致的页面唯一标题；「星图」一词仅指画布图元，不作界面名 |
| 大标题下 | 面包屑 | 领域层＝`知识探索`（单级，即当前层）；课程层＝`知识探索 / {课程名}`；**不含领域名**（领域身份只在领域层由下拉承载）；末级是当前层不可点，其余级可点回退 |
| 面包屑下 | 领域层＝领域切换器（下拉）；课程层＝**课程名行**（《课程名》＋课程介绍，纯文本） | 下拉只在领域层出现：默认第一个领域，切换只重算星图；课程层不挂下拉，要换领域先经面包屑回领域层——不出现「下拉在此、课在别处」的错乱，也不给课程层加第二套导航 |
| 页头右 | `使用手册` / `刷新` / `返回` 三枚（两视图共用同一组） | 手册为四页册（`help/sections.ts` 的 `HELP_PAGES`，每册同构三节＝功能概览／使用说明／状态与限制，节名唯一取自 `HELP_BLOCK_TITLES`），本页「使用手册」直落「知识探索」册（总册↔子页互链）；刷新＝重取**当前视图**数据（领域层 `star-map`、课程层该课层级数据）；返回＝回 `#/`；**不设「返回知识探索」按钮**（回退归面包屑） |
| 主体·领域层 | 星图画布（占满内容区） | 无统计行、无页内图例句、无轨迹/课程计数 |
| 主体·课程层 | 该课知识点**层级星图**（大知识点虚框＋框内小知识点条目，替换领域星图，§9） | 与领域层**同一暗色星空层**，图区**宽度跟随内容区实测宽度**、可缩放平移且任一框与条目都可达；**无浅色卡片**，虚框只作容器不铺白底 |

- **层级状态的唯一事实源＝URL**：`#/knowledge` 为领域层，`#/knowledge?course={course_id}` 为
  课程层。组件内不另存私有层级态；刷新、收藏、直接打开都落在对应层级；浏览器返回键天然回退一级。
- 点课程卡＝就地替换为课程层视图并写 `?course=`；点面包屑「知识探索」＝清参数回领域层，
  星图数据沿用 store 不重取（主体是条件挂载：回领域层时星图重新套满，画布的缩放/平移态不跨视图保留）。
- **面包屑不含领域名**：层级只有「知识探索 / 课程名」两级，领域身份只在**领域层**由下拉
  切换器承载（课程层不挂下拉）；回退出口只有「知识探索」一级。
- **面包屑两级全在本面内**，不通往学习／练习（独立面边界在单页形态下继续生效）。
- 图例与读图口径归使用手册（`help/sections.ts`「知识探索」册：功能概览讲同一竖列的课属同一条学习轨迹、课程卡连线＝先修；使用说明讲悬停课程卡看课程名称与介绍（竖虚线列框不响应悬停）、点击课程卡在本页下钻章节与知识点、悬停虚框读章节名称与摘要、悬停光点读知识点名称与摘要（名称常显在光点右侧）、点面包屑「知识探索」回领域全景、滚轮缩放与拖拽平移；术语按 2026-10-15 用户裁决统一：大知识点＝章节、小知识点＝知识点）。
- 手册弹窗配色与弹层形态不在本文复述：全站统一**蓝框白底深字**（星图页内的手册弹窗不随页面本体转暗），口径见 [frontend-overview.md](frontend-overview.md) §2「使用手册弹窗承载」；弹窗组件与首页共用 `components/HelpModal.tsx`。
- **首页联动口径**：首页 Hero 只保留大标题与简介段，**不出现**「学习中心仍在建设中…」一行
  （知识探索已开放）；「课程学习」「课后练习」两卡的「建设中」提示文案归各自面开放时消解；
  首页**不增设领域／学习路径信息面**——多领域展示由星图页左上领域下拉承载
  （`GET /learn/star-map` 一次返回全域）。

## 4. 背景层（星空图像 + CSS 动效）

`.kn-galaxy` 自上而下固定层序，任一层缺位只降级不报错：

| 层序 | 层 | 口径 |
| --- | --- | --- |
| 1（最上） | 三团 `radial-gradient` 辉光 | 蓝／紫／深蓝，色彩层次 |
| 2 | 压暗层 `linear-gradient(rgba(4,8,22,.5))` | 保证课程框、轨迹名与连线可读对比 |
| 3 | 星空图像 `url('/starfield.jpg') center / cover no-repeat` | 位图放 `web-ui/public/`，随构建拷入 dist；不引 npm 依赖 |
| 4（兜底） | 底色 `#070b1c` | 图片缺位时只剩渐变与底色，页面照常可用 |

其上叠两档 CSS 星点动效层（`::before` 细密漂移、`::after` 亮星呼吸），`pointer-events: none`，
`prefers-reduced-motion` 关闭动画；星图内容层 `z-index` 高于全部背景层。

## 5. 坐标系与套满系数（领域层布局 ↔ 渲染契约）

布局为纯函数 `starMapLayout(domain, edges, view) → StarMapLayout`，渲染层不做几何决策。

- view 来自 `ResizeObserver` 实测容器，只接受 ≥480×360，否则退回缺省 `STARMAP_VIEW`（1200×700）。
- 套满系数预乘：ECharts `graph`（`layout:'none'`）按成员点包围盒等比铺满 series 矩形而符号
  按 px 原样绘制，故布局侧预乘系数进坐标与框尺寸，并回传配对的 `chartMarginX/Y` 使渲染侧
  系数恰为 1；否则课程卡会掉出轨迹列框。
- 系数按列框相对包围盒最远伸出封顶，`MIN_SCALE`~`MAX_SCALE` 内先取整再套用（行距恰为
  `ROW_H × scale`）。
- `EChart` 尺寸变化时既 `resize()` 又 `setOption(option, true)`（系数 init 时算定，只 resize
  会停在旧取景）。
- 确定性：同输入同坐标（无随机无时间因子），vitest 断言同层共 y、列框包成员、列不压叠、
  连线必然下行、渲染系数为 1 且整体在画布内。

## 6. 森林版式：层＝行 × 轨迹＝列（领域层）

- **行＝层级 tier**：`tier = max(stage 档序, 先修拓扑深度)`；stage 档序取领域 `stages` 值序
  （基础 0／主干 1／分支 2／前沿 3，未知退回拓扑深度），有界松弛保证每条先修边严格下行；
  同 tier 共用一条 y，跨轨迹对齐成排。
- 行号稠密化：出现的 tier 映射连续行号，行距恒 `ROW_H × scale`，不留空行。
- **列＝学习轨迹**：一轨一列；列序 `kind=main` 优先→课程数降序→名字典序；核心列居中（x=0），
  其余按主次左右交替环绕，游标＝已排边界＋列间隙。
- 列内：同 tier 并排以列中心对称展开；行内顺序按父辈重心定序（两遍），减少交叉；
  无重心退回 course_id 字典序。列宽＝最宽行所需＋内边距。

## 7. 领域层图元：轨迹列框 / 课程框 / 先修连线

| 图元 | 形态 | 口径 |
| --- | --- | --- |
| 轨迹列框（星云） | 竖长 `roundRect`，透明填充＋同轨色 dashed 描边，核心列略粗略实 | 本轨全部课程框包围盒＋内边距推出；轨迹名写框内顶部名称带；上沿比最上排成员多让一行 |
| 课程框 | `roundRect`，不透明深底＋同轨色描边＋圆角 | 宽＝课名估宽（CJK 满宽/拉丁窄宽）＋内边距，高固定；字号随 scale 夹可读区间；**宁可框大，不可字糊** |
| 先修连线 | 同轨实线、跨轨虚线、无箭头 | 端点＝父框底边→子框顶边；弯曲度逐边选择绕开无关框 |

- 课程框必须不透明（link 端点锚节点中心，框半透明会连线穿框「连错位置」）。
- 不画轨迹间软链、不画课程圆点，连线只连课程框。
- 知识点计数不进图，也**不出现在悬停提示**：`kp_confirmed`/`kp_candidates` 仍由端点吐出并留在
  布局里（数据面不变），只是本面不再有展示位。
- 绘制层序：轨迹列框先入 `data`，画在连线与课程框之下。

## 8. 领域层交互：悬停、点击、缩放

| 对象 | 悬停 | 点击 |
| --- | --- | --- |
| 课程框 | 高亮（底色提亮＋白描边加粗＋标签转白）＋提示**两行＝课程名称（加粗）／课程叙述** | **就地下钻**：写 `?course={course_id}` 并把主体替换为该课知识点层级星图（§9），不跳新页 |
| 轨迹列框 | 无任何效果 | 无（`nebula:` 前缀节点 id 在回调过滤） |
| 画布空白 | 无 | 无；滚轮缩放、拖动平移（`roam`，缩放限幅） |

- 本节只述**领域层**图元；课程层的悬停口径见 §9（大知识点虚框＝框信息、框内条目＝名称＋摘要；
  课程层**不画层级关系线**，归属由虚框承载），两视图语汇同一套、各自成节不双写。
- 高亮写 series 级 `emphasis`（`scale:false`、`focus:'none'`），列框逐项 `emphasis:{disabled:true}`。
- 提示框对非课程节点返回空串。
- **课程叙述进提示框**：叙述＝`GET /learn/star-map` 的 `course.description`（8900 从 `qed_course`
  透传，与 §9 课程层的介绍同源同值）；长文按提示框限宽折行（`white-space: pre-wrap` + 最大宽度），
  **不截字符数**、不出现省略号吞句；`description` 为空时**只显课名一行**，不留空行占位。
- **计数行不进提示框**：提示固定两行＝课程名称（加粗）／课程叙述。
- **悬停提示不含复习段**：「今日复习 K 条」追加与 `GET /learn/review/due` 聚合调用整体移除
  （复习入口口径归练习独立面）。

## 9. 课程层级视图＝大知识点虚框星图（同页内，学习顺序自上而下）

- 视图位置：与领域星图**同一个页面**（§3）——主体由星图替换为本图，URL 写
  `#/knowledge?course={course_id}`；回退只走面包屑（`知识探索` 一级，**不含领域名**）或浏览器
  返回键，页头按钮组不变（仍三枚，**无「返回知识探索」按钮**）。
- 标题层：大标题仍是「学习中心·知识探索」（两视图一致）；面包屑末级显示课程名；
  面包屑下**不挂领域下拉，只有一行课程名**＝**《课程名》＋课程介绍**（`qed_course.description`
  经 8900 端点透传，纯文本；介绍为空只显课程名，不留占位行）；该行就是本视图的内容标题，
  **只显一处不与图区重复**。要换领域先经面包屑回领域层，本视图不出现第二套导航控件。
- **语义模型＝两级知识粒度**：本视图把课程内的层级读成**大知识点 → 小知识点**两档，
  而不是「章／节／知识点」三级文档结构——
  - **大知识点＝虚框容器**：现数据里的 outline depth1（俗称「章」）只是承载位，语义是一门课里
    成块的大知识点（例：线性代数的《行列式》《矩阵》，两章之间自有先后）；
  - **小知识点＝框内条目**：outline depth2（俗称「节」），例：《矩阵》框内的《矩阵乘法》《矩阵计算》；
  - **`point` 行（主表已确认知识点）同样是框内条目**：按 `parent_kp_id` 归入所属框（父为节时归到
    该节所在的大知识点框），与小知识点条目并列绘制，**不另立第三层**。
- **版式＝虚框自上而下按学习顺序堆叠、框内条目排网格**：
  - 大知识点框**单列纵向堆叠**，堆叠顺序＝该课的学习顺序（定序规则见下条）；框宽取**内容区实测
    宽度**（不钉成「条目数×固定宽」的内在尺寸），框高＝框内条目网格所需＋顶部名称带。
  - **框内条目按框宽自左向右折行排成行优先网格**（每格＝发光圆点＋名称标签），使条目多的框
    （现网单框最多 21 条）不致拉成超长列；条目顺序同样按定序规则。
  - 图元与领域层**同一套语汇**：虚框沿用 §7 轨迹列框的画法（`roundRect` ＋dashed 描边＋透明填充＋
    框内顶部名称带），条目沿用发光圆点＋名称标签；整幅画在同一暗色星空层上，**无浅色卡片底**，
    虚框也不铺不透明白底（只作容器）。
- **定序＝`order_hint` 优先＋来源锚页序兜底**：大知识点框与框内条目都按 `order_hint` 升序 →
  空值按**来源锚最小页码**（outline `source_ref.page_start`／point `anchors[].page`）→ 名称码点 →
  行 id 收尾。数据现状：outline 行 `order_hint` 全有值（非按父连续），`point` 行在候选确认时
  `order_hint` 为 NULL、只能经 PATCH 赋值，**页序兜底正是为 `point` 与将来补录的行服务**。
  **图上不画顺序号徽章，名称也不加序号前缀**——学习顺序只由虚框纵向堆叠与框内网格的行优先次序承载。
- **归属由虚框承载、层级连线取消**：包含关系由虚框几何直接表达，画布上**不出现任何边图元**；
  `parent_kp_id` 只用于归属计算，不产生连线与提示文案（布局侧无 `links`／`ownership` 字段）。
- **标签常驻两层**：大知识点名称带与框内条目名称**都常驻**，不做按缩放动态显隐（条目名是本面
  唯一的可读面）。
- **悬停＝学习者可见的信息**：
  - 大知识点虚框＝**大知识点信息**：名称＋`summary`（outline 摘要写入通道已实现；该行摘要为空时
    只显名称，属设计内降级）；
  - 框内条目（节／`point`）＝**名称＋一句话摘要**（`point` 取主表 `summary`；outline 行摘要同通道）；
    摘要为空只显名称，不留占位行；
  - **来源锚计数、四分类（`type`）、下辖计数一律不进提示**——编辑侧信息不进学习面。
- **未归档知识点不进学习面**：`parent_kp_id` 为空或悬空的 `point` 行**既不补画虚拟框、也不画该
  point**；本面不出现「未归档」概念的任何字样，其归属与承接归后台管理·文档分析处理（REQ-116）。
- **取景**：画布宽度取**内容区实测宽度**（由 `Knowledge.tsx` 的 `ResizeObserver` 观测内容区后传入
  视图，视图不自算宽度）；高度＝全部框的内在高度之和，高于容器时**纵向滚动**（框高与行距不随视口
  压缩）；**滚轮缩放与拖动平移（`roam`）开放**，判据＝缩放／平移后任一框与条目都可达，不出现
  「动了却看不到」的取景死角。圆点在两轴套满差下仍须保持正圆（`symbolSize` 的 y 分量按**实测**
  宽高比重算）。滚动条槽常驻（`scrollbar-gutter: stable`）：内容区宽度量测一次即稳定，
  不因内容超高出槽而把画布画宽一截。
- 点击框与条目**不跳页**、不引出新页面（知识点详情阅读归课程学习面）。
- 取数：`GET /learn/courses/{id}/knowledge-points?include_outline=true`（同一响应带 outline 行的
  `summary`，**零新增查询**）。
- **页面不含**：待选池与确认/驳回操作、手工登记候选写面、「已确认 N · 待选 M」统计行、轨迹 Tag、
  同名词多版本候选抽屉，以及**浅色画布底与实体白底卡片**；知识点写操作全部归后台管理·文档分析处理（REQ-116）。
- 空态：该课程**无任何大知识点框**（既无 outline 也无已归入的 point）→ 图区置空空态
  「该课程暂无已确认知识点」，课程名与介绍照常显示，不白屏、不画骨架；
  纯 outline（无 point 行）课程**照常出图**。

## 11. 已知约束与维护规则

- 8903 只连 8900（ADR 0007）：星图与课程层级数据一律经 8900 学习域端点。
- 暗色只在本页局部生效：页面级 `ConfigProvider` 罩住两视图（领域星图与课程层级星图**共用同一
  暗色星空层**，课程层图区直接画在星空上，不再有浅色卡），不改全局 token、不影响 admin 浅色页。
- **单页两视图是导航的唯一形态**：不得把两级视图拆回两个页面或做整页跳转；层级状态只由 URL
  查询参数（`?course=`）承载，组件内不保存私有层级态。
- **星图课程卡悬停必含课程叙述、必不含计数段**：提示固定两行＝课程名称＋课程叙述；
  `GET /learn/star-map` 的 course 对象缺 `description` 视为契约回归，出现「已确认 N · 待选 M」段
  视为回归旧形态。
- **面包屑不显领域名**：层级只有「知识探索 / {课程名}」两级；面包屑出现第三级（领域名）视为
  偏离本档。领域层的下拉切换器**只属领域层**：课程层左上角只显示课程名行，出现领域下拉视为偏离本档。
- **两视图同一套星图语汇**：课程层与领域层画在同一暗色星空层上，图元＝**大知识点虚框（dashed
  容器＋框内名称带）＋框内发光圆点＋名称标签**；出现**浅色画布底**或**实体白底卡片**视为回归。
  课程层**不画层级关系线**（包含关系由虚框承载），出现归属连线或「{子} 属于 {父}」提示视为回归旧形态。
- **学习面信息面收窄**：本面只向学习者展示**知识本身**——悬停固定为**名称＋摘要**（大知识点虚框与
  框内条目同此；摘要为空时只显名称）；**来源锚计数、四分类（`type`）、下辖计数**属编辑侧信息，
  出现即视为偏离本档（编辑面归后台管理·文档分析处理（REQ-116））。
- **图区宽度跟随容器且取景可达**：课程层画布宽度取内容区实测值；出现「固定内在宽度致虚框只占
  一小块、平移后超出部分不可见」视为回归。
- **学习面不出现「未归档」概念**：无父／悬空 `parent_kp_id` 的 point 行不进课程层图，图元与提示
  都不得出现「未归档」字样；该概念的承接面＝后台管理·文档分析处理（REQ-116）。
- **取景三定**：画布宽度取内容区实测值（框宽按其比例，不钉内在宽）、**高度取内在尺寸＋纵向
  滚动**（框高与行距不随视口压缩）、**名称标签常驻两层**（大知识点名称带＋框内条目名，不做按缩放
  动态显隐）。
- **不在图上画学习顺序号**：顺序只由堆叠与网格次序承载；出现序号徽章或名称前缀序号视为偏离本档。
- 布局与渲染分工硬边界：几何决策只在 `starMapLayout.ts`（领域层）与 `kpTreeLayout.ts`（课程层＝
  大知识点框＋框内条目网格几何），`StarMapGraph.tsx` / `KpTreeGraph.tsx` 只按布局画图。
- **无跨界出口是硬边界**：本面新增任何通往学习/练习的按钮都视为违反独立面边界，须先改本档。
- **课程图不画知识点间关系**：课程层连层级边都不画（归属由虚框承载）；先修 DAG 只存在于课程级，
  知识点之间无关系数据。引入知识点网状关系（GraphRAG）须另立项并先改本档。
- **本面零知识点写面**：候选确认/驳回/登记只在后台管理·文档分析处理（REQ-116）发生；本页出现任何写操作
  按钮视为越界。摘要写入通道只开放**服务端**写口径（PUT outline／PATCH 白名单含 `summary`），
  本面**不因此**出现录入控件。
- 改本档触发条件：图元形态、版式规则、交互口径、降级表现变化→先改档再改码；纯参数微调
  随码走，`starMapLayout.test.ts`／`kpTreeLayout.test.ts` 不变量断言同步。
- 端点与表结构不在本档复制：形状变化只改 api-contracts / database-design。
