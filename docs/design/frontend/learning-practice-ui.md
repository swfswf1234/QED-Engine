## 1. 定位与目标

本文档是「学习中心·课后练习」独立面（`#/practice`）的 **UI 设计事实源**：面内信息分区、
课程选择、题源选择 → 抽取预览 → 人工确认入库管线、题卡作答与判分回显、闪卡自评、
到期复习队列、错题本人工位、面内复习计数，以及空态与降级的用户可见表现。

它回答的是「学习者如何把一本书里的现成习题抽成题、答完即判、按节律回流复习，并把错题
管在自己的工位里」——这一切发生在**独立面**，不依附课程学习工作台。

- **服务对象**：学习者本人。
- **单一入口**：主界面（`#/`）「课后练习」卡是**唯一**上游入口；本面不放通往星图／工作台
  的操作按钮，其他面也不放进入本面的按钮（复习入口唯一落位本面「今日面板」）。
- **成功标准**：① 首页卡一点即达，选课即可开工，无需先进工作台；② 题只从书里来——抽取
  只出草稿、人工确认才入库、题面响应不含判分依据、无答案题自动转闪卡自评；③ 到期复习
  与错题本随课可见，人工位只改本人工位不改判分事实；④ 判分阈值与间隔序列零前端复制
  （只消费服务端结论字段）；⑤ 8900 或练习存储不可达时逐分区降级不白屏；⑥ 面间零跳转，
  复习计数入口在本面唯一化。

## 3. 页面信息面与导航

| 分区 | 内容 | 口径 |
| --- | --- | --- |
| 页头 | 大标题「学习中心·课后练习」＋课程选择器＋`返回` | 课程列表与工作台同源（`GET /learn/courses`）；**选项值＝共享课程目录坐标** `course_ref.ref_id`，无该坐标的学习课程不进选项；`返回` 回 `#/`；未选课各分区给「先选一门课」空态且不发请求 |
| 今日面板 | 一行计数＋到期复习队列（§6） | 计数与队列由**一次请求**同时给出（`max_tasks=100`，服务端上限）：截断前全量到期数给计数、`tasks` 给队列；队列被截断时尾行「另有 N 条到期未列，做完本批再看」；计数为 0 **仍渲染面板**（显示「今天没有到期」）——这是复习入口唯一落位 |
| 题源工作区 | 题源书＋页范围＋题解配对书 → `抽取题目` → 抽取预览与确认面板（§4） | 归属＝**课级**：本面无章/节选择器，入库 `kp_id` 只作可选标注，留空即课级归属 |
| 本课题卡 | 本课题列表（课级全量）→ `QuestionCard` 作答与判分回显（§5） | 列表不传 `kp`、不做客户端过滤；每题 `kp_id` 只作归属标签展示；列表响应不含判分依据（投影硬边界） |
| 错题本 | 派生行＋人工位（收藏/标记解决/重做本题）（§6） | 与到期队列**同屏两段**，不新开路由、不加 Tabs |

- **课程层级唯一事实源＝URL `?course=`**（与 `#/knowledge` 同判例）：深链可直达某课的练习面，
  选择器写 URL、URL 驱动取数，不在 store 里另存一份课程态。
- **计数行合并**：今日面板与错题本的头部计数合并为一行 `今日到期 N／错题 M 未解决（共 K）`，
  同屏不出现两处重复计数。
- 视觉上沿用 8903 全局浅色主题；本面是读写界面，不做暗色化（暗色承载例外只在星图面）。
- **面间零跳转**：不放「去学这本书正文」类按钮，防止与课程学习面再耦合；用户自行经首页切换三面。

## 4. 题源选择 → 抽取预览 → 人工确认入库

题源＝**书里现成的习题**（教材课后题或已下载习题集），整条链路不引模型：前端纯函数抽取
（§7）→ 确认面板人工复核 → 服务端批量入库。渲染基线（公式回原样、双定界符防御）与课程
学习面正文同一套。

- **题源书**：列表来自题源书目端点（形状见 api-contracts §⑥）——服务端按 `roles` 命中与课程
  归属过滤并**回传** `parsed_pages`（＝已解析出产物的页数）；「可选题源」判定由本面再叠加
  `parsed_pages > 0`，属**前端过滤、契约不变**——未解析书逐页必 404，选了也抽不出题，不进选项。
  选项文案＝`书名（角色）`（如 `数学习题集（exercises）`）；为空时 placeholder＝
  `本课暂无已解析的题源书`。
  **课程归属在服务端定**：书库行 `course_id` 空时回退解析表同列（现网书库行该列全空，
  2026-10-07 真机核验），前端不按书号前缀猜课。`source_kind` 由角色推出（exercises →
  `exercise_book`、textbook → `textbook_chapter`、solutions → `solutions_book`、其余 → `manual`），
  不由用户手选。
- **页范围**：`抽取起页`/`抽取止页`，输入过程保留在本地（store 只在两值齐备时视为合法，显示值
  取本地位）。校验＝整数、起 ≥ 1、止 ≥ 起、跨度 ≤ `EXTRACT_MAX_PAGES`（40 页）；非法**不发任何
  请求**，提示 `页范围不合法（需选择题源书，起止页齐备、不倒挂且不超过 40 页）`。
- **逐页取块**：按页号顺序逐页取该书页块（经 8900）。404＝跳过并计入提示
  （`第 N 页无解析产物（跳过）`）；非 404 失败终止整次抽取并 `notice`，草稿与预览清空。
- **题解配对书（可选）**：另一本书＋自己的页范围，选项**排除当前题源书**；配对后按题号建
  答案索引喂抽取，答案来源标 `sibling_book`，入库 `source_ref.answer_book_ref` 记配对书。
  系统不自动猜配对（知识点表的教材/习题引用不作 UI 默认值），人工手选。
- **抽取只出草稿**：`抽取题目` 后进预览卡（`抽取预览（人工确认后入库）`），**无自动入库路径**。
- **确认面板**逐题一行卡：题面（可改）、选项（只读＋`去掉选项`，选项不完整时转简答/闪卡）、
  `题型`（quiz/flashcard）、`作答形态`（choice/short/open）、`答案来源`
  （`same_page`/`solution_section`/`sibling_book`/`manual`/`none` 五值可选；`llm` 仍在类型与服务端
  闭集里，但**选择面把它滤掉**，界面不出现该值，见 §9）、评分依据（判分题，同步切关键词）、
  背文（闪卡）。头部一行 `草稿 N 题，可入库 M 题（不合格的不提交）`，不合格行缺项红字
  （缺题面/缺评分依据/缺背文/`none` 非闪卡/缺关键词/选项不完整）。
- **入库**：`确认入库` 只提交**零缺项**草稿 → 批量入库端点，整批带 `course_id`、
  `gen_batch=workbench-extract`（历史批次标识，**不随界面改名而改值**，见 §9；存量题行不迁移）、
  `kp_id`＝可选归属节点（留空＝课级）、`book_ref` 与 `source_kind`＝题源书、`kp_type` 快照。
  服务端按 `(course_id, stem_hash)` 跳重，回执 `入库 N 题（跳重 M）`；写后整体重取本课题、
  队列与错题本（不乐观更新）。全部不合格**不发请求**，提示
  `没有可入库的题（每题需题面 + 判分依据或闪卡背文，请补齐或删除）`。
- **面板侧校验与服务端同口径**（`draftIssues` 镜像服务端不变量）：题面必填、quiz 必须有评分
  依据、flashcard 必须有背文、`answer_source=none` 只能 flashcard、open 必须有关键词、choice
  必须有完整 `A-D` 选项——一批不因单题拖整批 422。
- **判分依据不在题面里**：题列表与复习队列响应不含 `expected_answer/keywords/explanation`；
  面板上「评分依据」是用户自填草稿值、非服务端回读；只有提交作答后的响应才回传判分依据。

## 5. 作答、判分回显与闪卡自评

- **题卡**＝本课题、到期项与错题重做**同一组件**，三种来源标记（`new`/`review`/`manual`）。
  choice 出单选、short/open 出文本框（题面或答案为空时提交禁用）；提交作答 → **就地展开判分
  结果**（`判对/判错`、`判分方式`、`趋势`、`judge_note`、`评分依据`、`解析` 走 Markdown＋KaTeX），
  不跳页、不清空题面。
- **flashcard 面**＝卡片翻转＋自评：`翻开背文` → `记得`/`重来` → 同一端点带自评结果
  （`method=self`，无判分）；`review_date` 由到期任务带入以保证同键唯一（重复提交 409 按状态
  冲突提示，题卡保留）。
- **结果文案按口径分两套（徽章词承载语义，判例 DEFECT-012）**：判分题结果卡标题＝`判对`/
  `判错`；闪卡自评＝`已记住`/`未记住`，**不套用对错措辞**——自评是记忆态确认，非答对答错。
  两套都同行显示 `判分方式`、`趋势`、`judge_note`；自评行不显示 `评分依据`/`解析`。
- **最近判分持久行（判例 DEFECT-013）**：面内汇总行除计数行外，最近一次作答或自评后追加
  `最近判分：〈口径〉·趋势 〈trend〉`（口径四值：`自评已记住`/`自评未记住`/`判对`/`判错`）。
  原因＝写后重取会使题卡整体卸载、卡内反馈随之消失，该行是唯一常驻反馈。事实源是 store 中
  最近一次作答响应；刷新/切课不清，仅页面卸载消失；只回显结论，不把判分依据写进列表响应
  （投影硬边界不变）。

## 6. 到期复习队列与错题本

- **到期复习（N）**：一次请求同时给全量到期计数与队列（`max_tasks` 取服务端上限 100）。
  本面按**课全量**呈现：端点无章节粒度参数，客户端也不按 `kp_id` 过滤，每题带 `kp_id` 归属
  标签展示。题粒度项直接给题卡（带 `错题优先`/`类型档` 标签与 `超期 N 天`）；知识点粒度项
  只给文字卡（`知识点复习（类型·档 x）`），无题可答时不硬造。
- **错题本（N）**：错题本端点的派生行（端点支持 `kp`，本面不传）：趋势标签（首答/进步/退步/
  持平）、`答错 w/a 次`、`今日到期`、上次作答原文；人工位 `收藏`/`标记解决` 走作答 PATCH，
  `重做本题` 就地展开同题卡（`origin=manual`）。头部一行 `刷新` 重取三张面。
- **人工位只改本人工位**：`bookmarked`/`resolved` 不进判分事务、不改判分事实；错题本不是
  独立表、不是独立页。
- **复习计数入口唯一化**：星图悬停段与课程知识点页页头按钮已移除，本课到期计数只在本面
  「今日面板」呈现；计数不落前端缓存，切课即重取；聚合失败按 0 显示「今天没有到期」不弹错。

## 7. 抽取纯函数规格（`exerciseParse.ts`）

与目录解析同级：**规格与纯函数一一对应**，夹具走真实页块文本，改动先改本节再改码。
本节是抽取规格的**唯一正本**（`exerciseParse.ts` 与确认面板头部 docstring 的「规格正本」指针
均指本节）。页范围上限常量 `EXTRACT_MAX_PAGES`（40）落在调用侧 `stores/practice.ts` 而非纯函数
模块；规格不变，常量不搬。

1. **块归一**（`exerciseBlocksOf`）：`formula`→`latex`、`table`→`html`、`list`→`items` 拼行，
   其余取 `text`；按 `(page, index)` 升序。
2. **块类型分流**：`header`/`footer`/`page_number` 不进题面，落未识别清单（`excluded`）；
   `image`/`table` 记**附件**（题面保留引用、置信 −0.15），无当前题可挂落 `no-anchor`；
   `formula` 按 KaTeX 安全形态包裹并入当前题干，无锚点同样 `no-anchor`。
3. **题号锚**：`^\d+(\.\d+)?$` 后紧跟顿号/点/右括号或空格才算新题起始；题号只作分组与答案
   配对键，不进题面正文；锚前行归并当前题（续行、多段）。
4. **章节标题切换答案区**：短行/heading 命中答案节标题（`答案与提示/参考答案/习题答案/
   解答与提示/solutions`）⇒ 进答案区，之后带题号行按题号累积**书内答案索引**（拆不出题号
   落 `answer-orphan`）；命中习题节标题（`习题/练习/课后题/补充题/problems/exercises`）⇒ 退出。
5. **答案来源优先级**：同页答案引导（`答案/解答/答/解/提示：`）→ 书内答案节索引
   （`solution_section`）→ 题解配对书索引（`sibling_book`）；三处无配 ⇒ `none`。置信度按来源
   降序（manual 1 / same_page 0.95 / solution_section 0.85 / sibling_book 0.6 / none 0.3），
   随 `meta.confidence` 入库。
6. **按答案形态定型**（`classifyAnswer`，模块私有未导出）：有选项且能定 `A-D` 单字母 ⇒ choice；
   有选项定不出字母 ⇒ 回落 flashcard（背文＝答案原文）；无选项且答案 ≤ 30 字不含句读 ⇒ short；
   可切 ≥ 2 关键词 ⇒ open（关键词 ≤ 6）；其余 ⇒ flashcard。**`none` 无答案题一律 flashcard**
   （不阻塞入库、走自评；人工补答案后经作答/题行 PATCH 升级 quiz）。
7. **`kp_type` 默认 `memory`**（调用方可覆盖），入库快照进题行供复习调度取序列；UI 不重算间隔。
8. **未识别行不静默丢弃**：三类原因（`excluded`/`no-anchor`/`answer-orphan`）逐条列面位置与
   页号，面板头部 `未识别 N 行` 汇总。

## 8. 状态与降级矩阵

| 场景 | 用户可见表现 | 口径 |
| --- | --- | --- |

## 9. 已知约束与维护规则

- 8903 只连 8900（ADR 0007）：题源书、页块、作答、队列全经 8900，不直连 8901/8902。
- **入口唯一**：`#/practice` 只由主界面「课后练习」卡进入；本面与其他学习面之间不得新增
  跳转按钮（回归由 `Practice.test.tsx`、`CourseKnowledge.test.tsx`、`LearnWorkbench.test.tsx`、
  `StarMapGraph.test.ts` 的零跨界断言守护）。
- **题面与判分依据分离（前端侧硬边界）**：题列表、复习队列与练习卡响应不含 `expected_answer/
  keywords/explanation`，只在提交作答后的响应展开；不得为显示答案另开读面。判分阈值与间隔
  序列不在前端复制。
- **抽取页数纪律**：单次按页范围逐页取块，跨度上限 40 页；不全书扫描、不缓存整书块文本，
  题解配对书同受上限。
- **写后重取**：入库、作答、人工位三处写后一律重取本课题/队列/错题本，不乐观更新。
- **抽取规格与纯函数同源**：§7 与 `exerciseParse.ts` 一一对应，改动先改本档再改码，
  `exerciseParse.test.ts`（习题页/答案节实测文本）夹具与不变量同步。
- **自评与判分两套文案是硬边界**（DEFECT-012 语义）：`method=self` 永不显示「判对/判错」。
- **`llm` 只从界面消失，不从契约消失**：`AnswerSource` 与服务端闭集保留 `llm`（不改契约），
  确认面板与抽取产物一律不产出该值——v1 绝不由模型作答；v2 生成出题落地时先改本档再动码。
- **批次标识不改值**：`gen_batch` 恒为 `workbench-extract`（该列带索引、语义是「整批可核销」的
  数据键，改值会造成同一管线两值并存）；独立面不重命名它，存量题行不迁移。
- **归属粒度＝课级**：题列表/队列/错题本一律不传 `kp`，客户端不做章节过滤；`kp_id` 只作归属
  标签与调度快照。
