### 1. 定位与目标

本文档是「学习中心·课程学习」面——**学习书架**（`#/learn`）与**三栏学习工作台**
（`#/learn/c/:courseId`，**单屏**：目录＋正文＋批注与推进同屏，无模式切换）——的 **UI 设计事实源**：
书架课程卡与注册闭环、三栏信息面、多教材顺序与目录选择规则、正文只读排版复用与分批口径、
目录页文本解析与自动生成／人工修正规格、批注→候选→确认登记闭环、勾选式推进与看板结课、
空态与降级表现。

它回答的是「学习者如何选一门课、对着一本书的正文把某一章/节的总结与详解就地写下来并
归入知识点树，同时按目录顺序逐节勾选推进直到结课」。知识点树在这里是**可学习的目录**：
章（`depth=1`）与节（`depth=2`）来自书籍目录页，细知识点（`point`）来自批注登记。

- **独立面声明**：本面承载「读与写（批注）」与「进度推进」；**不承载练习与复习**——
  出题、作答、到期复习、错题本全部归课后练习独立面（`#/practice`，见课后练习设计稿）。
- **入口唯一**：首页「课程学习」卡 → `#/learn` 书架 → 课程卡 → 工作台。知识点探索面
  （`#/knowledge` 两页）**不再有**「进入学习工作台」按钮（裁决 ④）。
- **服务对象**：学习者本人；不承载管理与运维功能。
- **成功标准**：① 首页卡一点即达书架，课程可注册可进工作台；② 一屏三栏，选章即读该章
  排版正文并就地登记批注，不需切页；③ 中栏正文与管理面解析视图同源同排版（不出现第二套
  渲染器）；④ 章节树进入课程即自动生成，每行可人工复核与整树修改（未识别行不静默丢弃）；
  ⑤ 批注叙述一律人工书写、带可回指来源锚点，确认前只进候选池；⑥ 进度**勾选式**、读时派生、
  断点可续，且**界面无「链路」概念**（推进所需的单元树由进场自动准备，对用户透明）；
  ⑦ 8900 或解析产物不可达时逐栏降级，不白屏。

  批次规则、目录页文本→章/节树解析规格与自动生成／整树修正规格、批注登记字段与闭环、
  单屏推进勾选与看板结课、空态与降级矩阵。
- **本档不管**（事实源改指）：端点形状/错误码/响应字段→api-contracts.md 学习域节；
  `qed_knowledge_point`/`qed_learn_kp_detail` 与 `node_kind`/`parent_kp_id`/`source_ref` 列语义
  →database-design.md；版式重排规则本体（字号阶梯、标题级差、目录启发式、符号表三列）→

- **非目标**：
  - **不做模型生成**：批注与候选叙述一律人工书写，界面不提供「生成」按钮（LLM 生成归主链 M-2）。

    也不出现链路／单元字样；单元树只是进场的后台准备动作（见 §9）。
  - **不做目录页位置的最终猜测**（R8 改判）：目录页与正文起页由进场自动定位试算，但**置信不足即
    降级人工**，不写入猜测值；全书扫描只消费已解析产物的块文本，不触发重新解析。
  - **不做三级以上层级**：章→节两级封顶，更深结构归 `point` 行或留在正文。

- **领域下拉＋顺序列表**：页头领域下拉（取 `GET /learn/star-map` 的 `domains`，默认第一个领域，
  切换只过滤不跳页）；课程**竖排逐行**，顺序键＝该领域内星图坐标（`track` 分组内按 `stage` 层级、
  同层级按 `sort_order`），即知识点探索面同一套「先修在前」的学习顺序，不在书架重排。
- **课程行信息面**：课程名＋状态徽章（词本身承载口径，不靠脚注）——`draft` 且无单元＝「待建链路」、
  `draft` 且已有单元＝「草稿」、`learning`＝`学习进度 XX%`、`completed`＝「已结课」；
  百分比取列表项 `derived.percent`（**不显示「已学 N 块」**，工作台看板不取该字段，见 §10）；
  教材横列在该行下方一行展示（R9）＝按学习顺序逐本一个小 chip，内容＝`序号 · 书名`，
  未激活解析版本者加降级标记（灰态＋「未激活」），当前所学那本高亮。
- **引用式注册（可多本并定序）**：弹窗选「共享课程＋已激活解析版本的书」，主素材可**多选并按选择
  顺序定序**（`resources` 数组按序写入，首本＝默认所学），写入只存 `ref_id` 与 label 快照，
  不复制书目内容；后续增删教材走同一弹窗重存。
- **id 桥**：路由 `:courseId` 用共享课程 id（与星图、课程知识点页同源），链路端点用 `lc-*`；
  桥＝课程列表里找 `course_ref.ref_id === courseId` 的首门匹配。同一共享课程注册多门学习
  课程时后注册者取不到链路（现状边界；并存需另设课程选择器，属新设计不在本档口径内）。

  「书目服务不可达（解析侧离线），暂不能选素材」，书架卡片与星图照常列出（独立性铁律，

### 5. 教材顺序与章节目录的选择规则

- **所学教材集合**＝课程 `resources` 里的 book 项，按注册顺序排列；只有 `course_id` 等于本课程
  **且** `active_job_id` 非空的书才贡献目录与正文。`active_job_id` 是「哪一版解析产物可读」
  唯一事实源；未激活版本的书在教材行显示灰态「未激活」，其章节**不进**拼接目录（不是置灰项）。
- **顺序学（R9）**：左栏是**一条**目录＝各本教材的章按教材顺序拼接，每本教材的章前出一个教材题行
  （不可选中、只作分区）；「当前所学」指针＝`derived.current_unit_id` 反查到的节所属教材，
  无进度时取顺序首本。跨教材不并行：拼接顺序即学习顺序，教材行不提供排序操作（改序需重注册）。
- **课程身份**从星图数据取（同一份 `GET /learn/star-map`），不在工作台再造课程目录端点。
- **目录树**＝`GET /learn/courses/{id}/outline`，**逐本教材带 `book` 参数分别取数**后按教材顺序拼接；
  返回扁平列表，层级由 `parent_kp_id` 与 `depth` 决定。
- **章/节正文范围**来自该行 `source_ref.page_start/page_end`（PDF 页序）。缺 `source_ref`、
  起止非整数、`page_start < 1` 或 `page_end < page_start` 一律视为**无范围**，中栏给
  「请在管理面补录」空态且**不发任何页请求**（不用 0 或整书范围兜底）。
- 切换所学教材不重置右栏批注归属以外的状态；写操作后重取目录，左栏计数跟随服务端（不做乐观更新）。

### 6. 中栏：正文只读排版与懒取批次

- **复用而非重造**：中栏用管理面 `BlockList`（版式模式），参数固定 `editMode=false`、
  `renderMode="layout"`、`imageSize=null`（回退 A4@96dpi）、`edits={}`，版式偏好取
  `loadTypographyPrefs()`（与解析管理同一份 localStorage）；块集合由 `blocksOf(pageData)` 归一。
- **批次规则**：进入章/节从 `page_start` 起一次请求 **8 页**（`PAGE_BATCH`），记 `loadedThrough`；
  `loadedThrough < page_end` 底部出「继续加载 N 页」，N＝`min(8, page_end − loadedThrough)`。
  并行发出、按页号升序渲染、已请求页缓存，重选同一节点不重复请求。
- **单页缺产物**＝404 按空态（`第 N 页：无解析产物`），不计错误不阻断；非 404 失败才显示错误文案。
- **点选块＝取锚点**：中栏每块可点选（批注取数动作，非编辑），选中态由 `BlockList` 高亮
  承担，再次点选取消；右栏据此显示锚点摘要。

### 7. 目录解析：进场自动生成与人工修正（`tocParse.ts` 规格）

**两个入口，一套规格**：① **自动生成**（默认，R8）＝进入课程时对每本已激活解析版本的教材后台执行
下列 1~4 步，命中即整树写入并刷新左栏，不弹窗、不需使用者给页码；② **人工修正**＝左栏「修改目录」
打开 `TocConfirmPanel`，可改`目录起页`／`目录止页`／`正文起页`（留空＝目录止页后一页）与逐行取舍后
整树覆写。自动生成的结果与人工写入走同一 `PUT …/outline` 形状，人工写入永远覆盖自动结果。
按页读解析产物块文本，逐块按行拆开（`tocLinesFromBlockTexts`，空行剔除）得**目录行**。**不引模型**：
章/节判定是纯函数＋（必要时）人工复核。

0. **页定位（自动）**：目录页＝块文本命中「目录 / Contents / 目 次」且其后若干页仍为「行＋尾页数」形态的
   起始页，止页＝该形态连续段的末页（不越过首个正文章题页）；正文起页＝首个章题在目录段之后的出现页。
   扫描只读已解析产物的块文本，**不触发重新解析**；跨教材各自定位。**置信不足即不写**：目录页未命中、
   拆行后无可用章题行、或偏移试算未命中 → 该本教材降级为「自动生成未完成，请点『修改目录』补页码」，
   绝不写入猜测值。
1. **行拆分**：目录页实测常为单 paragraph 块含多行，先按块序拼接再按行拆；行内尾数用版式面
   同一套 `tocItemParts`（不重造正则）。
2. **定级**：`第N章`（阿拉伯/中文数字、允许空格）与 `Chapter N` 判 `depth=1`；其余拆得出页码
   的行挂最近章题判 `depth=2`；两级封顶。
3. **印刷页→PDF 页偏移**：`offset = 首章标题正文侧首次出现页 − 目录印刷页`；正文侧出现页由
   「正文起页」起样本页试算，命中提示 `自动试算 N，可覆盖`，未命中人工填；偏移可改，预览重算。
4. **未识别行不静默丢弃**：`设计内剔除`（前言/序/后记/致谢/索引/参考文献/附录/习题类）、
   `缺页码`、`缺所属章题` 逐条列原因；目录页罗马页码行与「目录」标题行属版式噪声先行剔除。
5. **写入形状**：章/节 `page_start/page_end` 由印刷页＋偏移推出，相邻首尾相接（本节 end＝
   下一节 start−1，末章取全书页数），越界回夹 `[1, pageCount]`；确认后整树
   `PUT /learn/courses/{id}/outline`（幂等替换，`book_ref`＝书目级 `book_id`）；叶节点＝
   `children: []`（DEFECT-010 判例：服务端不下探空列表、不算第三级）。
5.1 **重名口径**：节名仅同一章内唯一，同父重名整树拒（422）；跨章同名合法（DEFECT-011 裁决：
   主表 `(course_id, book_ref, norm_key)` 只有普通索引）；`kp_id` 复用查找按「父级＋名」建键。
6. **失败口径**：写入失败按 8900 错误包络提示，不抛异常、不清空用户已改行。
7. 空树时确认按钮禁用，不把空目录写进主表。

### 8. 右栏批注登记与候选闭环

- **字段**：用途（`总结`/`详解`，`intent` 闭集，默认`详解`）、知识点名（必填）、四分类
  （`概念/程序/记忆/设计`，可空，对应 `type`）、批注正文。用途与四分类正交，不互相推断。
- **锚点**：中栏点选块 → `anchors=[{kind:'book', ref_id:book_id, page, snippet}]`（页＝PDF
  页序）；未点选也可登记（`anchors=[]`），提示「不选＝无锚点登记」。
- **归属**：`parent_kp_id`＝左栏当前选中章/节；未选中时提示「先在左栏选中章/节，批注才有
  归属」并禁用登记。`book_ref` 随书写入。
- **闭环**：`保留为候选`＝`POST /learn/kp-details`（`gen_status=candidate`）→ 立即重取本章候选；
  候选行标注 `用途·状态`，开放态行给 `确认入库`/`驳回`（确认＝提升主表，重复名 409 回显；
  驳回＝不落主表可重批）。每次写后重取本章候选与目录计数。知识点名空**不发请求**。
- 本界面**永不**出现「编辑已确认知识点」入口：本面对知识点主表只有「候选 → 确认入库」一个
  写入方向；已确认行的改名与删除**当前无界面承载**（2026-10-11 二审把课程知识点页定为零写面
  的层级关系图，知识点写操作只在本工作台发生）。

### 9. 单屏推进与看板结课（链路退为后台准备，界面不出现）

- **单屏（R7）**：无模式切换。左栏目录、中栏正文、右栏批注＋推进勾选常驻同一屏，选节即读、即写、
  即勾选；不存在「另一种浏览形态」。
- **后台准备（对用户透明）**：进场后按顺序自动完成——目录为空者先按 §7 自动生成 → 目录变化时对
  每本教材 `PUT …/syllabus`（`chainFromOutline` 章→节 1:1 映射，节带 book＋页窗）→ 逐单元
  `PATCH confirmed`。三步无按钮、无进度条、无「链路」文案；失败只在右栏推进区出一行降级提示＋
  `重试`，不阻断阅读与批注（阅读/批注不依赖单元树）。
- **进度仍落单元行（服务端硬约束）**：`POST …/progress` 只接受单元行（非 unit 行 409），
  `percent`/`current_unit_id`/`completed` 全由单元派生，故界面勾选的是「本节」，写入的是该节对应的
  单元——**映射键＝同一父级下的同名同序节**（拼接目录时按教材分别建链，跨教材不串名）。
  界面不暴露单元 id 与单元概念。
- **不触发编译**：`compile/propose` 与 `compile/start` 不出现在本面（后端 `compile` 仅骨架兜底出块，
  正文两侧都是按页窗取同一份解析产物），编译状态字段不在本面消费；如后续需要块物化另立设计。
- **块内容口径**：正文按该行 `source_ref` 页窗懒取当前生效版本解析产物，复用 `BlockList
  renderMode="layout"`（parsing-ui §9/§9.1）；image 块整页页图＋`bbox` 内联裁切
  （`pageImageUrl` 入参，parsing-ui §9），无地址/无 bbox 回退题注。
- **推进语义（勾选式）**：右栏`本节学完`勾选 → `POST …/progress`（`done`/`skipped`/`pending`）＋
  `PATCH /learn/units/{id}` `covered`；服务端不自动推进，界面不复制掌握门与判分逻辑。
  同一勾选态回显在左栏该节行尾。
- **看板与结课（只读）**：推进区只消费 `GET …/courses/{lc}/progress`
  （total/done/skipped/percent/completed），跨教材合并计一门进度（total＝全部教材单元数）；
  进度读时派生重算，撤销勾选数字自然回退、断点指回该节。写后一律重取，不乐观更新。
- **断点与续学**：`derived.current_unit_id` 指示断点→ 反查左栏对应节并高亮，页头/推进区给
  `回到断点`；`drift`（源漂移）标记在左栏该节行尾以「目录已变，请重生成」文案呈现（内部即 drift）。
- **结课态**：`completed` 时推进区出「已结课」面板；勾选可撤销，重算后面板随之消失。

### 11. 已知约束与维护规则

- 8903 只连 8900（ADR 0007）：正文页、书目、目录、知识点全部经 8900。
- 页序口径唯一：中栏分页、锚点 `page`、`source_ref` 一律是解析产物 PDF 页序；印刷页只出现在
  目录行与偏移换算；正文页范围按当前生效版本解释。
- 渲染复用硬边界：版式规则只在 `components/parsing/typography.ts` 与 `BlockList`，工作台不
  复制排版分支；新渲染口径先改解析管理面设计。
- 解析规格与纯函数同源：§7 规格（含步 0 自动定位）与 `tocParse.ts` 一一对应，改动先改本档再改码，
  `tocParse.test.ts`（b05 目录页实测文本）夹具与不变量同步。
- **「链路」不出界面是硬边界（R7）**：单元树（syllabus/units）只作进度的存储载体，由后台自动准备；
  本面不出现模式切换、链路/编译按钮与「单元」字样。若某设计需要把链路显性化（如多版本并行学习），
  须先改本档并用户裁决。
- **进度只能记单元行**（服务端约束，api-contracts.md:1019）：勾选「本节学完」写的是该节映射到的单元；
  想改记在 outline 章节行属于服务端契约变化，走大修改另立任务。
- **多教材只有一条顺序（R9）**：教材顺序＝注册顺序，跨教材串行不并行；改序通过重注册，不提供拖拽排序。
- 候选池是唯一写面：批注不直接写知识点主表，主表只接受确认动作。
- **练习语义移出是硬边界**：本面不出现题卡/抽取/队列/错题本组件；如练习面需回工作台
  （合并形态），须先改本档与 C 稿并用户裁决。
- **面间零跳转（R2＋R5 已裁）**：本面与知识点探索面、课后练习面之间**不留任何按钮级跳转**
  （工作台「返回星图」与书架「知识星图」均移除）；三面互切只经首页三卡。入口链唯一＝
  首页「课程学习」卡 → 书架 → 工作台。
- 写后重取：目录计数、候选清单、推进面板一律重取，不做乐观更新。
- 改本档触发条件：三栏信息面、批次规则、解析规格、归属与闭环口径、推进与看板、降级表现
  变化→先改档；纯样式微调随码走。
- 端点与表结构不在本档复制：形状变化只改 api-contracts / database-design。
