## 1. 定位与目标

本文档是「学习中心 · 三栏学习工作台」（`#/learn/c/:courseId`）的 **UI 设计事实源**：三栏信息面、
书与章节目录的选择规则、正文只读排版的复用与分批口径、书籍目录页文本的解析与人工确认规格、
批注 → 候选 → 确认的登记闭环、练习面（抽取式题源 → 人工确认入库 → 作答判分）与本章复习队列、
空态与降级表现。

它回答的是「学习者如何对着一本书的正文，把某一章/节的总结与详解就地写下来并归入知识点树，
并把同一本书里的现成习题就地抽成题、答完即判、按节律回流复习」。
知识点树在这里是**可学习的目录**：章（`depth=1`）与节（`depth=2`）来自书籍目录页，
细知识点（`point`）来自批注登记。

- **服务对象**：学习者本人，与星图同属学习中心；不承载管理与运维功能。
- **成功标准**：① 一屏三栏，选章即可读到该章排版正文并就地登记批注，不需切页；
  ② 中栏正文与管理面解析视图同源同排版（同一套版式规则，不出现第二套渲染器）；
  ③ 章节树来自目录页文本解析且每一行都可人工复核（未识别行不静默丢弃）；
  ④ 批注叙述一律人工书写、带可回指的来源锚点，确认前只进候选池；
  ⑤ 8900 或解析产物不可达时逐栏降级，不白屏；
  ⑥ 题只从书里来：抽取只出草稿，人工确认才入库，题面响应不含判分依据，无答案题自动转闪卡自评；
  ⑦ 到期复习与错题本随章可见，人工位（收藏 / 已解决）只改本人工位、不改判分事实。

## 2. 范围与非目标

- **本档管**：工作台三栏的信息面与交互口径、书与章节目录的选择规则、正文分页批次规则、
  目录页文本 → 章/节树的解析规格与确认写面、批注登记的字段与闭环、练习面的题源选择与
  抽取/确认/入库/作答口径、本章复习队列与错题本人工位的呈现、空态与降级矩阵。
- **本档不管**（事实源改指）：
  - 端点形状、错误码与响应字段 → [api-contracts.md](../../../architecture/api-contracts.md 学习域节；
  - `qed_knowledge_point` / `qed_learn_kp_detail` 两表结构与 `node_kind`/`parent_kp_id`/`source_ref` 列语义，
    以及练习三表（`qed_learn_question`/`attempt`/`review_task`）结构
    → [database-design.md](../../../architecture/database-design.md；
  - **判分阈值与复习间隔序列表的取值**（choice/short/open 三型阈值、`kp_type` 五档间隔）
    → 服务端事实源（`services/learn/grading.py`、`services/learn/practice.py`）与其契约行，
    UI 只消费 `is_correct/method/score_trend/review` 字段，**不在界面复制任何阈值**；
  - 版式重排规则本体（字号阶梯、标题级差、目录启发式、符号表三列）→
    [parsing-ui.md](../../design/parsing-ui.md §9.1 与 `web-ui/src/components/parsing/typography.ts`；
  - 星图版式与图元 → [learning-star-map.md](learning-star-map.md)；
  - 解析产物的生成与版本激活 → [parsing-flow.md](../../design/parsing-flow.md。
- **非目标**：
  - **不做模型生成**：批注与候选的叙述一律人工书写，界面不提供「生成」按钮；
    模型生成候选属学习域后续设计面，其落点是候选池同一张表，不改变本界面的字段口径。
  - **不出题**：v1 题源＝书里现成的习题（教材课后题 / 已下载习题集），抽取是纯函数 + 人工确认，
    界面不出现「让模型出题」入口；两段式·服务端装配生成（v2）另批实施，届时只替换题源侧、
    确认面板与题卡面不变。
  - **不做主观题的模型批改展示**：open 题只按关键词命中判分并回显 `judge_note`，
    不呈现模型意见（v1 关闭）。
  - **不做错题本独立页**：错题本随右栏，不新开路由。
  - **不做块编辑与判定**：中栏只读，不出现编辑弹层、判定按钮与「确认块」入口。
  - **不做目录页自动定位**：目录页起止页由使用者给出，系统不从全书扫描猜目录位置。
  - **不做三级以上层级**：章 → 节两级封顶，更深的结构归 `point` 行或留在正文。

## 3. 三栏信息面与导航

| 栏 | 宽度 | 内容 | 口径 |
| --- | --- | --- | --- |
| 页头 | — | 左＝课程名 + 轨迹（来自星图数据），右＝`返回星图` | 不再放统计数；返回一律回 `#/knowledge` |
| 左 | 280px | 书选择器 → `导入目录` 按钮 → 章节目录列表（章顶格、节缩进，行尾带该节已确认知识点计数） | 列表来自 outline 行，章/节按 `depth` 缩进；选中项高亮 |
| 中 | 自适应（`flex:1`） | 卡题＝`正文 · 第 a–b 页`（PDF 页序）；正文按版式重排只读渲染，逐页带页号小标；**正文下方＝练习区**（题源书 + 页范围 → 抽取预览与确认面板 → 本章题卡作答） | 正文无编辑 affordance；批次未完时底部出「继续加载 N 页」；练习区见 §8/§9 |
| 右 | 320px | Tabs 两页签：`批注与候选`＝批注表单（用途 / 知识点名 / 四分类 / 正文）→ `保留为候选` → 本章候选清单（确认入库 / 驳回）；`本章练习`＝到期复习 + 错题本两段（收藏 / 标记解决 / 重做本题） | 表单区在上，清单在下；回执文案统一走 `notice`；两页签共用本章口径（按选中章/节过滤） |

- **进入路径**：课程知识点页（`#/knowledge/c/:courseId`）页头「进入学习工作台」按钮。
  星图画布内**不加**第二枚可点元素（画布已承载选中/悬停/下钻三态，再加按钮会挤掉徽标口径）；
  复习条数因此只写进课程节点的**悬停提示行**，可点的复习入口放在课程知识点页页头
  （`今日复习 N 条`，N=0 时不显示）。
- **练习区随章/节出现**：中栏练习区与右栏 `本章练习` 都在选中章/节之后才挂载（未选中时练习无归属，
  入库与队列都没有父级）。右栏默认页签＝`批注与候选`，读写主路径不因练习面而改变。
- **三栏是同一屏的三种角色**：左＝定位（学到哪），中＝内容（正文说什么）＋就地练习（题答得怎样），
  右＝产出（我怎么写）与复习（该回炉什么）。
  任何一栏的写操作只改右栏或左栏的数据，不跳动、不整页刷新。
- 视觉上沿用 8903 全局浅色主题（管理面同源），不做星图那样的局部暗色化——工作台是读写界面。

## 4. 书与章节目录的选择规则

- **可选书**＝`course_id` 等于本课程 **且** `active_job_id` 非空的书目。`active_job_id` 是
  「哪一版解析产物可读」的唯一事实源；未激活版本的书不出现在选择器里（不是置灰），
  因为它没有可渲染的正文。书目为空时选择器 placeholder＝`本课暂无已激活解析版本的书`。
- **课程身份**从星图数据取（同一份 `GET /learn/star-map`），不在工作台再造课程目录端点。
- **目录树**＝`GET /learn/courses/{id}/outline`，切书时带 `book` 参数重取；返回的 outline 行是扁平列表，
  层级由 `parent_kp_id` 与 `depth` 决定。
- **章/节的正文范围**来自该行的 `source_ref.page_start/page_end`（PDF 页序）。校验规则：
  缺 `source_ref`、起止不是整数、`page_start < 1` 或 `page_end < page_start` 一律视为**无范围**，
  中栏给「请在管理面补录」空态，并且**不发任何页请求**（不用 0 或整书范围兜底，那会渲染出错误正文）。
- 选书会重置右栏归属与中栏已加载页；写操作后重取目录，使左栏计数始终跟随服务端（不做乐观更新）。

## 5. 中栏：正文只读排版与懒取批次

- **复用而非重造**：中栏用管理面的 `BlockList`（版式模式）渲染，参数固定为
  `editMode=false`、`renderMode="layout"`、`imageSize=null`（回退 A4@96dpi）、`edits={}`，
  版式偏好取 `loadTypographyPrefs()`（与解析管理同一份 localStorage 偏好）。
  块集合由 `blocksOf(pageData)` 归一（数组或 `{blocks}` 两种产物形态都吃）。
- **批次规则**：进入某章/节时从 `page_start` 起一次请求 **8 页**（`PAGE_BATCH`），记录「已发起加载的
  最后一页」`loadedThrough`；`loadedThrough < page_end` 时底部出「继续加载 N 页」，
  N＝`min(8, page_end - loadedThrough)`。请求并行发出，渲染按页号升序；已请求页保持缓存，
  重选同一节点不重复请求。
- **单页缺产物**＝该页 404，按**空态**处理（`第 N 页：无解析产物`），不计错误、不阻断其余页；
  只有非 404 的失败（离线、5xx）才在该页位置显示错误文案。
- **点选块＝取锚点**：中栏每块仍可点选（这是批注的取数动作，不是编辑动作），选中态由 `BlockList`
  的高亮承担；再次点选同块＝取消选择。右栏据此显示锚点摘要。

## 6. 目录解析与确认（`tocParse.ts` 规格）

入口＝左栏「导入目录」弹窗：填 `目录起页`、`目录止页`、`正文起页`（留空＝目录止页后一页），
按页读解析产物块文本，逐块按行拆开（`tocLinesFromBlockTexts`，空行剔除）得到**目录行**，
交给确认面板 `TocConfirmPanel`。**不引模型**：章/节判定是纯函数 + 人工复核。

1. **行拆分**：目录页的实测形态常是单个 paragraph 块内含多行，故先按块序拼接再按行拆；
   行内尾数用版式面同一套 `tocItemParts`（不重造正则）。
2. **定级**：`第N章`（阿拉伯或中文数字、允许空格）与 `Chapter N` 判 `depth=1`；其余拆得出页码的行
   挂到**最近的章题**下判 `depth=2`；最深两级，第三级不再接受。
3. **印刷页 → PDF 页偏移**：`offset = 首章标题在正文侧首次出现的页 − 该章在目录里的印刷页`。
   正文侧出现页由「正文起页」起的若干样本页试算；命中则提示 `自动试算 N，可覆盖`，
   未命中提示人工填。偏移人工可改，预览随之重算。
4. **未识别行不静默丢弃**，逐条列出并标注原因：
   `设计内剔除`（前言/序/后记/致谢/索引/参考文献/附录/习题一类）、
   `缺页码`（拆不出页码）、`缺所属章题`（节题出现在任何章题之前）。
   目录页自身的罗马页码行与「目录」标题行属版式噪声，先行剔除、不进未识别清单。
5. **写入形状**：章/节的 `page_start/page_end` 由印刷页 + 偏移推出，**相邻首尾相接**
   （本节 `page_end` ＝下一节 `page_start − 1`，本章 `page_end` ＝下一章 `page_start − 1`，
   末章取全书页数），越界回夹到 `[1, pageCount]`。确认后整树
   `PUT /learn/courses/{id}/outline`（幂等替换，`book_ref` ＝书目级 `book_id`）；面板对每个节点都发
   `children` 数组，**叶节点＝`children: []`**（服务端不下探空列表，也不把它算作第三级）。
5.1 **重名口径**：节名只在**同一父级（同一章）内**要求唯一，同父重名整树被拒（422）；
    **不同章同名节合法**——真实教材目录里「级数」「幂级数」「积分」「高阶导数」等节名跨章重复是常态，
    主表 `(course_id, book_ref, norm_key)` 只有普通索引、不是唯一键（DEFECT-011 裁决），
    复用 `kp_id` 的查找同样按「父级 + 名」建键，避免第 7 章的「级数」错误复用第 3 章的行。
6. **失败口径**：写入失败按 8900 错误包络给提示（如 422「目录树最深两级」），不抛异常、不清空用户已改的行。
7. 空树（一行章题都没解析出来）时确认按钮禁用，避免把空目录写进主表。

## 7. 右栏 `批注与候选` 页签：批注登记与候选闭环

- **字段**：用途（`总结` / `详解`，对应 `intent` 闭集，默认`详解`）、知识点名（必填）、
  四分类（`概念/程序/记忆/设计`，可空，对应 `type`）、批注正文。四分类只回答「这是什么种类」，
  用途只回答「我为什么写它」，两者正交，不互相推断。
- **锚点**：中栏点选的内容块 → `anchors=[{kind:'book', ref_id:book_id, page, snippet}]`
  （页＝PDF 页序，片段＝该块文本）。未点选也可登记（`anchors=[]`），提示文案明示「不选＝无锚点登记」。
- **归属**：`parent_kp_id`＝左栏当前选中的章或节；未选中时表单提示「先在左栏选中章/节，批注才有归属」，
  登记按钮禁用。`book_ref` 随书写入，供后续按书聚合。
- **闭环**：`保留为候选`＝`POST /learn/kp-details`（`gen_status=candidate`）→ 立即重取本章候选；
  候选行标注 `用途·状态`（如 `总结·待确认`、`详解·已入库`），开放态（草稿/待确认）行给
  `确认入库` 与 `驳回`：确认＝提升知识点主表（重复名词按 409「状态冲突」回显），
  驳回＝不落主表、可重新批注。每次写后重取本章候选与目录计数。
- 知识点名为空时**不发请求**，直接提示「知识点名必填」。

## 8. 中栏练习区：题源选择 → 抽取预览 → 人工确认入库

题源＝**书里现成的习题**（教材课后题或已下载习题集），整条链路不引模型：前端纯函数抽取（§8.1）→
确认面板人工复核 → 服务端批量入库。渲染基线（公式回原样、`$$$` 双定界符防御）与 §5 的正文同一套。

- **题源书**：列表来自 `GET /learn/question-books?course=`，选择面只含 **`roles` 非空且已解析出页产物**
  （`parsed_pages>0`）的书——未解析的书逐页必然 404，选了也抽不出题，故不进选项；选项文案＝`书名（角色）`，
  如 `数学习题集（exercises）`。为空时选择器 placeholder＝`本课暂无已解析的题源书`。
  **课程归属在服务端定**：书库行 `course_id` 为空时回退解析表同列（现网书库行该列全空，2026-10-07 真机核验），
  前端不再自行按书号前缀猜课。`source_kind` 由角色推出
  （exercises→`exercise_book`、textbook→`textbook_chapter`、solutions→`solutions_book`、其余→`manual`），
  不由用户手选，避免与书目角色打架。
- **页范围**：`抽取起页` / `抽取止页` 两个数字框，输入过程保留在本地（store 只在两值齐备时视为合法，
  所以显示值取本地位而不是 store 值）。校验＝整数、起 ≥1、止 ≥起、跨度 ≤ `EXTRACT_MAX_PAGES`（40 页）。
  非法时**不发任何请求**，提示 `页范围不合法（需选择题源书，起止页齐备、不倒挂且不超过 40 页）`——
  不用整书范围兜底，那会把全书拖进一次抽取。
- **逐页取块**：按页号顺序逐页 `GET /books/{id}/pages/{n}`（经 8900）。404＝该页无解析产物，
  **跳过**并计入提示（`第 N 页无解析产物（跳过）`）；非 404 失败（离线/5xx）终止整次抽取并给 `notice`，
  草稿与预览清空。
- **题解配对书（可选）**：另一本书 + 它自己的页范围，选项**排除当前题源书**（同书自配无意义）。
  配对后按题号建答案索引喂给抽取，答案来源标 `sibling_book`，入库时 `source_ref.answer_book_ref` 记下配对书。
  系统不自动猜配对关系（`qt_knowledge` 的 `textbook_ref/exercise_ref` 不作 UI 默认值），由使用者手选。
- **抽取只出草稿**：`抽取题目` 之后进预览卡（`抽取预览（人工确认后入库）`），**没有任何自动入库路径**。
- **确认面板**（`ExerciseConfirmPanel`）逐题一行卡：题面（可改）、选项（只读 + `去掉选项`，用于选项不完整时
  转简答/闪卡）、`题型`（quiz/flashcard）、`作答形态`（choice/short/open）、`答案来源`
  （`same_page`/`solution_section`/`sibling_book`/`manual`/`none`，**不含 `llm`**——v1 不由模型作答）、
  评分依据（判分题，同步切关键词）、背文（闪卡）。头部一行 `草稿 N 题，可入库 M 题（不合格的不提交）`，
  不合格行的缺项以红字标出（缺题面 / 缺评分依据 / 缺背文 / 答案来源为「无」却非闪卡 / 缺关键词 / 选项不完整）。
- **入库**：`确认入库` 只提交**零缺项**的草稿 → `POST /learn/questions`，整批带
  `course_id`、`gen_batch=workbench-extract`、`kp_id`＝当前选中章/节、`book_ref` 与 `source_kind`＝题源书、
  `kp_type` 快照。服务端按 `(course_id, stem_hash)` 跳重，回执 `入库 N 题（跳重 M）`；
  写后整体重取本章题、队列与错题本（不做乐观更新）。全部草稿都不合格时**不发请求**，
  提示 `没有可入库的题（每题需题面 + 判分依据或闪卡背文，请补齐或删除）`。
- **面板侧校验与服务端同口径**（`draftIssues` 镜像 `_question_invariant_error`）：题面必填、
  quiz 必须有评分依据、flashcard 必须有背文、`answer_source=none` 只能是 flashcard、
  open 必须有关键词、choice 必须有完整 `A-D` 选项。这样一批不会因单题把整批拖成 422。
- **判分依据不在题面里**（前端侧后果）：题列表与复习队列的响应不含 `expected_answer/keywords/explanation`，
  面板上看到的「评分依据」是用户自己填的草稿值，**不是服务端回读**；只有提交作答后的响应才回传判分依据。

### 8.1 抽取纯函数规格（`exerciseParse.ts`）

与 §6 的目录解析同级：**规格与纯函数一一对应**，夹具走真实页块文本，改动先改本档。

1. **块归一**（`exerciseBlocksOf`）：`formula`→`latex`、`table`→`html`、`list`→`items` 拼行，其余取 `text`；
   按 `(page, index)` 升序处理。
2. **块类型分流**：`header`/`footer`/`page_number` 不进题面，逐条落未识别清单（原因 `excluded`）；
   `image`/`table` 记为**附件**（题面保留引用、置信 −0.15），无当前题可挂时落 `no-anchor`；
   `formula` 按 KaTeX 安全形态包裹后并入当前题题干，无锚点时同样 `no-anchor`。
3. **题号锚**：`^\d+(\.\d+)?$` 之后紧跟顿号/点/右括号或空格才算新题起始；题号只作**分组与答案配对键**，
   不进题面正文。锚之前的行归并到当前题（续行、多段）。
4. **章节标题切换答案区**：短行或 heading 命中答案节标题（`答案与提示/参考答案/习题答案/解答与提示/solutions`）
   ⇒ 进入答案区，之后带题号的行按题号累积成**书内答案索引**（原因 `answer-orphan` 给拆不出题号的行）；
   命中习题节标题（`习题/练习/课后题/补充题/problems/exercises`）⇒ 退出答案区。
5. **答案来源优先级**：同页答案引导（`答案/解答/答/解/提示：`）→ 书内答案节索引（`solution_section`）
   → 题解配对书索引（`sibling_book`）；三处都没配到 ⇒ `none`。置信度按来源降序
   （manual 1 / same_page 0.95 / solution_section 0.85 / sibling_book 0.6 / none 0.3），随 `meta.confidence` 入库。
6. **按答案形态定型**（`classifyAnswer`）：有选项且答案能定出 `A-D` 单字母 ⇒ choice；
   有选项但定不出字母 ⇒ 回落 flashcard（背文＝答案原文）；无选项且答案 ≤30 字、不含句读 ⇒ short；
   可切出 ≥2 个关键词 ⇒ open（关键词 ≤6 个）；其余 ⇒ flashcard。
   **`none` 无答案题一律 flashcard**（裁决 ⑨：不阻塞入库，走自评；人工补答案后经 `PATCH` 升级 quiz）。
7. **`kp_type` 默认 `memory`**（可由调用方覆盖），入库时快照进题行供复习调度取序列表；UI 不重算间隔。
8. **未识别行不静默丢弃**：三类原因（`excluded`/`no-anchor`/`answer-orphan`）逐条列出面位置与页号，
   面板头部给出 `未识别 N 行` 汇总。

## 9. 作答、本章复习队列与错题本

- **题卡**（`QuestionCard`）＝中栏本章题、右栏到期项与错题重做的**同一组件**，只有三种来源标记
  （`new`/`review`/`manual`）。choice 出单选、short/open 出文本框（题面为空或答案为空时提交禁用）；
  提交 → `POST /learn/attempts` → **就地展开判分结果**（`判对/判错`、`判分方式`、`趋势`、`judge_note`、
  `评分依据`、`解析` 走 Markdown + KaTeX 渲染），不跳页、不清空题面。
- **flashcard 面**＝卡片翻转 + 自评：`翻开背文` → `记得` / `重来` → 同一端点带 `self_result`
  （`method=self`，无判分），`review_date` 由到期任务带入，保证同键唯一（重复提交 409 按状态冲突提示）。
- **结果文案按口径分两套（徽章词承载语义）**：判分题（`method` 为规则/模型判分）结果卡标题＝
  `判对` / `判错`；闪卡自评（`method=self`）结果卡标题＝`已记住` / `未记住`，**不套用对错措辞**——
  自评是记忆态确认，不是答对答错，混用会让用户以为自评被服务端判分。两套都同行显示
  `判分方式`、`趋势`、`judge_note`，自评行不显示 `评分依据` / `解析`（这两列自评不返回）。
  同一区分延伸到右栏汇总行（见下条）。
- **右栏顶行持久最近判分**：`本章练习` 头部一行除 `到期 N／错题 M 未解决（共 K）` 外，
  最近一次作答或自评后追加 `最近判分：〈口径〉·趋势 〈trend〉`（口径取 `自评已记住` /
  `自评未记住` / `判对` / `判错` 四值之一）。原因＝写后重取会使中栏与右栏题卡整体卸载，
  卡片内的判分反馈随之消失；该行的事实源是 store 的最近一次作答响应，`刷新` 与切章不清，
  只在页面卸载时消失。它只回显结论，不因此把 `expected_answer` 写进列表响应（投影硬边界不变）。
- **右栏 `本章练习`＝两段**（一页签内，不新开路由）：
  - `到期复习（N）`＝`GET /learn/review/due?course=` 的**客户端按本章过滤**（端点无 `kp` 参数，
    过滤口径＝`target_id` 是本章节点，或题行的 `kp_id` 属本章节点）。题粒度项直接给题卡
    （带 `错题优先/类型档` 标签与 `超期 N 天`）；知识点粒度项只给文字卡（`知识点复习（类型·档 x）`），
    因为无题可答时不硬造题。
  - `错题本（N）`＝`GET /learn/mistakes?course=&kp=` 的派生行：趋势标签（首答/进步/退步/持平）、
    `答错 w/a 次`、`今日到期`、上次作答原文，人工位两个按钮（`收藏` / `标记解决`）走
    `PATCH /learn/attempts/{id}`，`重做本题` 就地展开同一题卡（`origin=manual`）。
    头部一行 `到期 N／错题 M 未解决（共 K）`，`刷新` 按钮重取三张面。
- **人工位只改本人工位**：`bookmarked`/`resolved` 不进判分事务，也不改判分事实；
  错题本不是独立表、不是独立页，UI 只在右栏一节呈现。
- **复习入口（跨页聚合）**：星图按当前领域的课程列表逐个 `GET /learn/review/due?course=&max_tasks=1`
  取 `total_due`，写进课程节点提示行 `今日复习 N 条`（0 条不写）；课程知识点页页头在同一条数上出按钮，
  点击进工作台。计数与条数都**不落前端缓存**，切换课程/领域即重取。

## 11. 已知约束与维护规则

- **8903 只连 8900**（ADR 0007）：正文页、书目、目录、知识点全部经 8900；页面不得直连 8901/8902。
- **页序口径唯一**：中栏分页、锚点 `page`、`source_ref.page_start/page_end` 一律是**解析产物的
  PDF 页序**，不是书的印刷页码；印刷页只出现在目录行与偏移换算里。正文页范围始终按当前生效版本解释。
- **渲染复用是硬边界**：版式规则只在 `components/parsing/typography.ts` 与 `BlockList`，
  工作台不得复制一套排版分支；需要新的渲染口径时先改解析管理面设计。
- **解析规格与纯函数同源**：§6 的规格与 `tocParse.ts`、§8.1 的规格与 `exerciseParse.ts` 一一对应，
  改动先改本档再改码，`tocParse.test.ts`（b05 目录页实测文本）与 `exerciseParse.test.ts`
  （习题页/答案节实测文本）的夹具与不变量断言必须同步。
- **题面与判分依据分离（前端侧硬边界）**：题列表、复习队列与练习卡的响应**不含**
  `expected_answer/keywords/explanation`；这三列只在提交作答后的响应里展开。界面不得为了显示答案
  另开一条读面（那会绕过投影）。判分阈值与间隔序列不在前端复制——UI 只渲染服务端给的结论字段。
- **抽取的页数纪律**：单次抽取按页范围逐页取块，跨度上限 40 页；不做全书扫描、不缓存整本书块文本，
  题解配对书同样受该上限约束。
- **练习面写后重取**：入库、作答、人工位三处写操作后一律重取本章题 / 到期队列 / 错题本，
  不做乐观更新（与 §4 的目录计数同一口径）。
- **候选池是唯一写面**：批注不直接写知识点主表；主表只接受确认动作。因此本界面**永不**出现
  「编辑已确认知识点」的入口（那是课程知识点页的职责）。
- **改本档的触发条件**：三栏信息面、批次规则、解析规格（含 §8.1 抽取规格）、归属与闭环口径、
  复习队列与错题本呈现、降级表现变化 → 先改本档；
  纯样式微调（宽度、间距、色值）随码走，不必回改本档。
- **端点与表结构不在本档复制**：形状变化只改 api-contracts / database-design，本档最多改消费语义。

## 12. 学习书架（`#/learn`）

- **课程卡列表**：`GET /learn/courses` 每门课一张卡，状态徽章词本身承载口径（不靠脚注解释）——
  `draft` 且无单元＝「待建链路」、`draft` 且已有单元＝「草稿」、`learning`＝「在学 N%」、
  `completed`＝「已结课」；概览百分比取列表项 `derived`（工作台看板不取该字段，见 §13）。
- **引用式注册**：弹窗选「共享课程 + 已激活解析版本的书」，写入只存 `ref_id` 与 label 快照，
  不复制书目内容。
- **id 桥**：路由 `:courseId` 用**共享课程 id**（与星图、课程知识点页同源），链路端点用 `lc-*`；
  桥＝在课程列表里找 `course_ref.ref_id === courseId` 的**首门匹配**。同一共享课程注册多门学习
  课程时后注册者取不到链路（现状边界；要并存需另设课程选择器，属新设计不在本档口径内）。
- **降级独立性**：书目（8902 透传）与课程／星图**分开取数**——解析侧离线只把素材下拉降级为
  「书目服务不可达（解析侧离线），暂不能选素材」，书架卡片与星图照常列出（独立性铁律）。

## 13. 「阅读／链路」双模式、推进与看板结课

- **模式切换**：工作台顶栏 Segmented 受控切换「阅读」（＝§3~§9 的目录 + 批注 + 练习面）与
  「链路」（块序列 + 推进），两模式共用左栏位置与中栏渲染组件；右栏 Tab 随模式换面板。
- **链路生成**：`GET …/courses/{id}/outline` 取节级页窗 →「从目录生成链路」＝`PUT …/syllabus`
  写 `source_ref`（book + 页窗）→「全部确认」＝逐单元 `PATCH` 使两级确认齐备 →「编译链路」＝
  `POST …/compile/propose` + `…/compile/start`。两级确认未齐备时编译由服务端以「状态冲突」拒绝，
  界面原样透传该提示，不做前端预检。
- **块内容口径**：链路模式的单元按其 `source_ref` 页窗懒取该书当前生效版本的解析产物，复用
  `BlockList renderMode="layout"`（与阅读模式同一渲染基线，规则见
  [parsing-ui.md](../../design/parsing-ui.md §9/§9.1）；image 块用整页页图 + `bbox` 内联裁切
  （`pageImageUrl` 入参，parsing-ui §9），无地址或无 bbox 回退题注文字。
- **推进语义（勾选式）**：「学完」由学习者勾选 → `POST …/progress`（`done`/`skipped`/`pending`）
  ＋ `PATCH /learn/units/{id}` 的 `covered`；服务端不自动推进，界面不复制掌握门与判分逻辑。
- **看板与结课（只读）**：推进面板与结课面板只消费 `GET …/courses/{lc}/progress`
  （total/done/skipped/percent/completed），不改任务状态；进度是**读时派生重算**，故撤销勾选后
  数字自然回退、断点指回该单元。写操作后一律重取，不做乐观更新（与 §4 目录计数同口径）。
- **断点与续学**：`derived.current_unit_id` 指示断点，「回到断点」在左树选中并滚动到该单元；
  单元树上的 `confirmed` / `drift`（源漂移）/ `gen_status` 标记常显。
- **结课态**：`completed` 时链路区出结课面板（「已结课」）；勾选可撤销，重算后面板随之消失。

| 链路场景 | 用户可见表现 | 口径 |
| --- | --- | --- |
| 尚无单元 | 「从目录生成链路」为主操作，中栏空态 | 链路是生成产物，不是目录副产品 |
| 确认未齐备就点编译 | 服务端「状态冲突」提示原文透传 | 前端不预检、不猜测放行 |
| 编译进行中 | 按钮置忙 + 轮询编译状态 | `202` 后台任务 |
| 单元无页窗 | 该单元标「无页窗」，中栏不发页请求 | 与「无解析产物」分开表述 |
| `progress` 端点不可达 | 看板区错误文案 + 重试，块序列照常 | 逐面板降级，不整体白屏 |
