# ADR 0004：项目定位为个人图书馆与三中心形态

状态：Accepted
日期：2026-08-09
领域：架构与边界
决策阶段：v0.1
取代：—
被取代：—

## 背景

项目起源文档（`docs/history/QED设计文档.txt`）以高等数学学习为起点。随学习范围扩展，
2026-08-09 用户决定将项目定位从「个人高等数学学习系统」调整为「个人图书馆」：个人核心领域为
数学与计算机科学（AI 方向），资料类型覆盖教材、习题集、论文、博客与官方文档；学习交互参考
港大 DeepTutor 等智能学习项目。README 开篇定位段与 AGENTS.md 项目目标段（对外门面与执行入口）
已按新定位同步修订。

## 决定

1. **定位**：项目是长期演进中的**个人图书馆（Personal Library）**系统，当前以高等数学学习
   起步；个人核心领域为数学与计算机科学（AI 方向），后续随学习需求扩展。
2. **三中心形态**：学习中心（课程学习 + 知识问答）是前端主界面（`#/`）的最终形态、向用户
   展示的核心功能；管理中心（文档下载管理 / 解析进度 / 原始文档对照）与控制中心（服务启停
   托管）是后台内容与运行控制，对用户透明。
3. **探索阶段**：项目仍处探索阶段，形态随学习需求持续演进；本定位以 ADR 锁定，后续调整须
   新增 ADR 取代。
4. **参考对象**：学习交互参考港大 DeepTutor 等前沿智能学习项目，不绑定具体实现。

## 后果

- README.md 与 AGENTS.md 的定位表述随本 ADR 修订；项目发生大变动时（REQ-021）同步检查本
  ADR 是否仍成立。
- 课程体系、知识点模型与问答链路设计上不绑定具体学科（见学习中心设计「学科与资料边界」）。
- 资料获取与解析范围扩展到论文、博客与官方文档，由 QED-Tracker / Axiom-Flow 按既有流程承接。
