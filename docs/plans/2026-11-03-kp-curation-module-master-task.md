## 目标与成功标准

**目标**＝让「知识点梳理」这一个模块有**一处**说得清链路、断点与逐段承载的总任务面：解析产物进来、
章与知识点出去、确认后落共享主表、由学习面消费——这条链路上每一段要么有唯一在册行承载，要么被
明确定性为断点并给出归属；学习者与梳理者都能知道「梳理到哪一步算完、缺的那一环归谁补」。

条目化判据正本在台账行（ADR 0023，REQ-151 行 S1~S5）；行内 S 与本壳工作项的对应＝S1→W2、
S2→W4、S3→W3、S4→W1、S5→W1＋门禁。本壳不复制判据全文，只承接拆解、取证与归属裁定。

## 范围与非目标

**范围内**（只做模块级统筹，不新增任何一条细则判据）：

- **链路逐段承载表**＝把「解析完毕 → 未梳理判定 → 选书 → 目录梳理／重新解析目录 → 内容解析 →
  整理成知识点 → 落表 → 优化与美化 → 详情确认 → 落共享表 → 界面呈现」十一段各自指认唯一在册行
  与唯一写入端点，缺口按 F 项定性；
- **断点取证**＝四处断链级发现的原文取证（文件·行号·读数）与定性，落本壳「现网取证」节；
- **F2-5 只读探针**＝重做目录时的 supersede 语义与「两枚在册章骨架并存」风险的真机只读取证，
  取证后交用户裁归属；
- **归属裁定登记**＝F 项逐条给「由哪一行承载／是否另登新行／是否待裁」，改动在册行归属只按用户
  裁决随步（ADR 0022 决定 5），本壳不自行动判据。

**非目标（各给指针）**：

- 梳理屏的前端形态与 8900 透传＝**REQ-141**；生成腿（解析目录／内容解析／一键总结）＝**REQ-143**；
  块标注与页域识别＝**REQ-142**；版式几何复刻＝**REQ-140**；核查正本与缺口清单＝**REQ-138**；
  对方条文·通路·端点三面＝**REQ-139**；
- 确认位列与口径落真＝**REQ-148**（同批承接 F1-1 确认入口与 F1-4 改锚入口，判据进其壳 W 行）；
- `type` 四分类的生产与搬运链＝**REQ-152**（用户 2026-11-03 令「允许修改」，AF 改码授权随该轮记录）；
- 课程级归并与探索去书化＝**REQ-145**；习题两级闸＝**REQ-149**；习题链＝**REQ-146**；
- 内容面补齐与序列对账＝**REQ-150**；
