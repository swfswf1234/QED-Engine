## 目标与成功标准

**目标**：根仓库 8903「文档解析管理」编辑模式新增**框图工作台**——用户在原文页图上直接
拉伸/删除/新增/合并「取字框」，并把**框图作为该页的解析输入**（「解析本页」按当前框图逐
区域识别出字）。这需要 8902 提供区域驱动解析与块结构编辑两项当前不具备的能力。
需求定义方=根仓库用户，**实施形态（表结构/内部设计）由 Axiom-Flow 侧自定**，
本稿只给能力需求与消费侧验收判据。本文件为**根侧讨论稿**，已于 2026-09-26 经用户
授权复制移交至 `Axiom-Flow/docs/plans/2026-09-26-parsing-region-edit-typography-request.md`
（对方承接壳 PLAN-018 + REQ-099 支线行，其契约测试 181 全绿）；对方台账为实施事实源。

**成功标准**：R1～R5 逐条获得对方回执（接受/改造/拒绝+排期）；R1～R3 落地后根侧
REQ-098 框图结构操作全量启用并按判据联调通过。

## 范围与非目标

**范围**：能力需求清单（下表 R1～R5）＋承接与回执跟踪。

**非目标（边界，不要求对方）**：不改 OCR/版面引擎选型与模型部署（ADR 0014）；
不要求根侧参与对方实现设计；R1/R2 落库位置（af_* 表内或产物侧文件）由对方按其自身
存储规范自定（ADR 0018 元数据入 DB 口径由对方侧自行核对）；知识库面/检索链路改动；
根侧 8903/8900 的实现（归 REQ-098）。

## 能力需求清单

| # | 能力 | 需求描述（做什么） | 验收判据（消费侧观察） |
| --- | --- | --- | --- |
| R1 | **区域驱动页解析** | 单页解析任务以该页**已落库框图**（区域矩形列表）为识别单元：每个区域出一个块、块文字=框内取字；引擎默认检测与框图的调和策略（框间空隙归属、未覆盖区域是否丢弃）由对方设计，但结果须满足判据 | 画 3 个框→解析本页→该页恰 3 块且 bbox≈框、文字为框内内容；对已解析页改框后再解析，块随框变化 |
| R2 | **块结构编辑 API** | 页级块的**删除/合并/新增区域（空框待识别）**持久化编辑：语义建议走覆盖层（不动引擎原始产物、消费时合并，与现有 block edit 覆盖层同族），具体方案对方定；**合并块=并集 bbox、文本按阅读序拼接**；删除块在合并视图与后续重解析中都不再出现 | PUT 结构操作后 GET 页数据即回显新结构；刷新/重启后仍在；重解析后删除块不复活、新框出字 |
| R3 | **页框图读取视图** | 页数据（现有 `GET /books/{id}/pages/{no}` 或其扩展）返回**当前生效区域集合**：每区域含几何（含人工修正后）、关联块（或 pending 新框/已删除标记）——8903 画布唯一数据源 | 已解析页返回区=块数+新框数；corrected_bbox 生效后区几何为修正值 |
| R4 | **目录（TOC）块类型**（低优先） | blocks 类型枚举现无「目录」；请在版面判定中识别目录页/目录块（或提供可消费属性），供 8903 版式重排区分样式；承接前根侧用前端启发式兜底 | 对含目录页的样本书，目录块类型/属性可被消费侧区分命中 |
| R5 | **节题类型修正与多栏取字完整性**（2026-09-26 消费侧实测增补） | 样本 b05（Rudin《数学分析原理》中译本）版面识别两类缺陷：①p4「前言」/p5「重要符号表」/p7「目录」节题均判为 paragraph（应为 heading/节题类），且目录正文挤入单个含大量 `\n` 的 paragraph；②双栏页（p5/p7）右栏块**文本为空**（整栏取字丢失）。请在引擎侧修正节题类型判定并保证多栏块取字完整（实施形态对方定）；承接前消费侧以白名单类标题 + pre-wrap 换行保真启发式兜底 | b05 重解析后：p5/p7 节题块类型可与正文区分；双栏页右栏块文本非空、行结构完整 |
