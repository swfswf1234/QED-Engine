## 目标与成功标准

把 8903 文档解析管理的**版式**模式从「按角色启发式重新排版」改判为「**按解析几何复刻原书版面结构**」：
字号档、左缩进、居中与段距全部由块级 `bbox` 与 `image_size` 推得，`type` 与 `level` 不再参与层级判定；
段落合并腿删除；页眉页脚按「从严少删、只隐不删」的三条件判据隐藏，人工可回显并可后续判断删除。
本轮**明确忽略解析侧的类型与层级误判**，只用现有产物把结构渲对。

验收判据的唯一正本在 [todo.md](../trackers/todo.md) 的 REQ-140 行「成功标准」列，本节不复制条目。

## 改判设计稿（待评审，评审通过后迁入 `design/frontend/parsing-ui.md`）

- **R1 几何优先、类型让位**：版式渲染的四路几何量全部由块几何推得，缩放系数 `scale = 渲染栏宽 / image_size[0]`。
  - **基准行高 H**：取该页「块高 ÷ 文本行数」的分位值（行数＝`\n` 计数＋1；无换行的单行块按 1 行）。基准取页内还是跨页见 **Q1**。
  - **字号档**：`ratio = 块行高 / H`。`ratio ≥ 1.35` → 标题档、`0.75 ≤ ratio < 1.35` → 正文档、`ratio < 0.75` → 小字档；三档映射到既有中文字号阶梯（正文＝用户偏好档，标题＝其上一档），**阈值须以 b07／b05 真页现场标定并把读数留壳**，不凭设定直接采用。
  - **左缩进**：`(x0 − 栏左缘基线) × scale`，栏左缘基线＝该页正文块 `x0` 的分位值（档位取值同样由标定证据定）。
  - **居中**：块中心 `(x0+x1)/2` 与正文栏中心偏差 ≤ 栏宽 5% 且块宽 < 栏宽 60% ⇒ `text-align: center`（实测 b07 p10 两枚标题即为此形态）。
  - **段距**：相邻块纵向间隙 `(y0_next − y1_prev) × scale` 分档（紧接／分段／大隔），大隔视为段落分隔证据，替代当前写死的 `marginTop/Bottom`。
  - 公式／图片／表格块只消费其 bbox 的缩进与居中，不套文字字号档。
- **R2 删除同页段落合并**：`layoutUnits` 的「相邻两个纯文本块且前块未收尾 → 并成一段」整腿删除，`isSentenceClosed` 与无分隔符字符串拼接一并退役。依据＝用户 2026-10-24 判据「当前切分正常，版式合并段落反而打乱了结构，没必要合并」。跨页续段的处置单列 **Q2**。
- **R3 页眉页脚「从严少删、只隐不删」**：隐藏须**同时**满足三条，缺一不隐——
  ① `type ∈ {header, footer, page_number}`；② 几何落页边带（上缘 `y0 ≤ 页高 8%` 或下缘 `y1 ≥ 页高 92%`）；③ 短文本（`page_number` 恒满足；`header/footer` 文本 ≤ 40 字符）。
  不删＝块始终留在产物与序列里：流式模式照常逐块显示，版式模式由工具栏「显示页眉页脚」开关整体回显（现 `DEFAULT_TYPOGRAPHY.showFurniture` 默认 false 保留）。
  人工删除通路＝已册在的块结构编辑端点 `PUT /books/{id}/pages/{no}/structure`（全量声明、缺席即撤销），本壳不请求新端点。
  依据＝用户 2026-10-24 指令「尽量去除页眉页脚，标准放严一些少删，人工可以后续判断进行删除」。
- **R4 目录形态改由几何＋行式触发**：`toc` 渲染腿（点线引导＋页码右对齐，`BlockList.tsx:139-160`）保留，但触发判据从「白名单全文等值」改为「**前一几何标题块 + 其后连续多行块，且每行尾部命中页码形态**」。
  依据＝b07 p7 的标题实文「目录 MULU」使白名单必然失配（DEFECT-023 判据①）。
- **R5 流式不动、两模式分工保留**：流式继续逐块出卡片与「#n · 类型」标记，作为解析核对面；几何档只被版式分支消费。

**待裁点（立项轮不默认采纳）**

- **Q1 字号基准取页内还是跨页**＝甲・页内分位（局部最保真，目录页整体自洽，但连续滚动时跨页字号会跳）；乙・全书分位（跨页一致，但正文占比极低的页会被压成小字档）；丙・正文众数桶为全局基准＋页内只做分档（跨页稳且目录页不失真，代价＝需一次全书聚合，单页态取不到时回退甲）。**建议丙，回退甲**。
- **Q2 跨页续段合并是否保留**＝学习工作台拼章正文（`learnWorkbench.ts:143`）依赖同一条 `layoutUnits`，原动机是「一页一块、句子从中间断开」。甲・两条腿都删（最简，学习面可能出断句）；乙・只删同页并、保留跨页并并把收尾正则补全半角句号与省略号（**建议**）；丙・学习面另走独立纯函数、与解析面解耦。
- **Q3 是否引入绝对定位复刻档**＝甲・本轮不做（**建议**，理由＝与「文字完整展示不截断」硬约束冲突、长段落溢出与图文叠压风险）；乙・另加一档「像素复刻」开关供对照需求。
- **Q4 三档字号够不够**＝甲・三档（标题／正文／小字，**建议**）；乙・四档（再加「大标题」档，需真书页面上有可标的两级标题）。
