> 排期范围＝仅根仓库（用户裁决 2026-09-22）。

## 目标与成功标准

**目标**：为链路块序列供给 quiz/flashcard 题目源，并让错题与知识点按间隔节律回流复习。

| # | 标准 | 判据 |
| --- | --- | --- |
| T1 | 出题管线（L6）：三向位 Explore→Plan→每题 loop + 严格 JSON + normalize/校验/一次 repair，产出题带知识点四分类标注与服务端 expected_answer | 定向测试（repair 路径含坏 JSON 样本） |
| T2 | 间隔复习（L3 MySQL 化）：按类型间隔表 + 连对升档/连错降档 + 错题知识点最高优先；调度纯函数单测 | 8900 定向测试 |
| T3 | 错题双写题库：判分结果 best-effort upsert 题库（含 user_answer/correct_answer/is_correct/score_trend），错题本查询端点可用 | 契约测试 + 真机走查 |

## 范围与非目标

**范围**：8900 出题管线、复习调度器、题库表与错题本端点；mimic 试卷仿题（后置评估）。

**非目标**：判分/门槛/推进状态机（主链 M-3——本壳只调用其规则层，不复制语义）、
题目渲染与错题本页面（M1 UI-4）、LLM 降级开关本体（M3）、检索式出题（依赖 ARCH-025 线，
需要时按跨项目协作规范另行提出）。
