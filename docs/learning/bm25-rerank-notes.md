## 学习范围

1. **BM25**：词频/逆文档频率加权评分、参数（k1/b）、与向量检索的互补性（专有名词、公式、
   编号等精确词），数学文档检索的注意点。
2. **混合检索（Hybrid）**：向量 + BM25 并行召回 → 分数融合（RRF / 加权和）的方案对比。
3. **Rerank 重排**：粗召回后精排模型（如 bge-reranker）的作用、部署形态与成本。
4. **QED 落地**：检索链路（切片 → 向量化 → BM25 + 向量 → rerank）与 99% 检索成功率的
   评测口径。
